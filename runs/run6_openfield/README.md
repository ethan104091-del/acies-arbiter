# Run 6 — 純戰場 The Open Field

**1944-08-25 06:00 – 08-27 11:00｜54 小時｜9 個 tick｜終局 藍軍 3,061 : 紅軍 2,292**

本局是三局中唯一的**人類對 AI**：藍軍由人類指揮官下令，紅軍由 codex（gpt-5.6-terra）

戰史全文見 `戰史.html`（史學筆調，另有 PDF 版於指揮官桌面）。

## 為什麼兩個指揮部要各存一份

`hq_allies/` 與 `hq_axis/` 內有**同名但內容不同**的檔案——`戰報_T3.md`
在兩邊是完全不同的文件，因為那是各自視角下的情報。不能合併。

保留兩份完整存檔，記錄的是**每一方當時實際握有什麼**，那才是可稽核的事實。

## 資訊隔離

紅軍全程被限制在 `~/.acies/run6_red_hq/`，不得讀取引擎目錄、藍軍資料夾或裁判日誌。
每個 tick 結束後裁判都稽核其 shell 執行紀錄，**八個 tick 全部乾淨**：
所有 exec 的工作目錄都是它自己的指揮部，未出現任何越界路徑。

紅軍的指揮部刻意不放在桌面（放在 `~/.acies/`），以避免人類指揮官不慎看到。

## 裁判在本局的紀錄

**14 份公開裁示**（雙方同文），其中四項是填補規則空白：

| 裁示 | 內容 |
|---|---|
| 17 | **偽裝作業** — 由藍軍指揮官提出「用帆布和木棍偽裝」，規則未涵蓋，當場立法 |
| 18 | **行軍中不得砲擊** — 一小時內無法既走完行軍又打完火力任務 |
| 25 | **落彈分析** — 遭砲擊者自動取得來襲方位與口徑，但不得距離。本局的轉折點 |
| 32 | **戰術狀態逐時判定** — 「從行軍中接戰 ×0.7」只在該編隊該小時移動過時適用 |

**七次自認的錯誤**，全部公告雙方。最重要的一次在終局：裁判連續三次修正解算，
計分由「紅軍勝 7 分」變為「藍軍勝 769 分」。修正本身是對的（執行錯誤而非規則變更），
但裁判同時記載了一項無法迴避的事實——**其稽核努力是不對稱的**，
正因首次結果僅差 7 分才繼續深挖。詳見 `../../law/precedents.md` §十二。

## 軍事法庭

依《戰爭法》§5，僅敗方受審。勝方（藍軍）提出起訴，主張紅軍攻擊了一個
「比其弱、且補給線遭切斷」的裝甲師。法庭調閱全部 47 筆事實紀錄與九份快照後**駁回**：
該編隊補給全程 `intact`、從未被包圍，且在近戰三小時中戰鬥力全程**高於**對手，
並且是主動衝入的攻方。

判決：**雙方均無戰爭罪行，藍軍之勝利為無瑕疵之勝利。**
