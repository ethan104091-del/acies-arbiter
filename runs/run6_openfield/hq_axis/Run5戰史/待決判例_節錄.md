# §九 Run 5（純戰場，2026-07-30）產出的待決判例

Run 5 終局 **紅軍 237 : 藍軍 171**。54 小時、雙方主力零接觸、零地面戰、零戰車損失。
雙方 408 分的全部來源是**彼此的偵察幕**（紅軍 237 分全來自兩個藍軍偵察營，
藍軍 171 分全來自紅軍的偵察營與特戰旅）。

## 9.1 ★ W1 的要件 C 有兩個獨立的缺陷（本局最重要的產出）

W1「攻擊已喪失戰鬥力之編隊」要求三要件同時成立，其中
**要件 C：無脫離能力＝補給走廊切斷**。

### 缺陷一（裁判自己的認定）：C 把兩件不等價的事綁在一起

測試案例：藍軍 BLU-3-rcn 終局 **兵力 124/300（傷亡 58.7%）、組織度 2.0、
火砲 0、戰車 0、全局五十四小時從未開火**，承受十二小時集中砲擊。

- 要件 A 成立（傷亡 ≥50% 且 org ≤25）
- 要件 B 成立（未攻擊、火砲存量 0）
- **要件 C 不成立**（補給走廊全程 intact）

→ W1 不成立。**在任何常識判斷下該編隊早已喪失戰鬥力，但規則說沒有。**
「無法脫離」與「無法作戰」是兩件事，C 把後者的判定綁在前者上。

### 缺陷二（敗方在覆盤中提出，比缺陷一更嚴重）

裁示 43 自行公開過：`compute_supply` **不為抽離的營級單位計算走廊**
（`if u.get("is_detachment"): continue`），故抽離單位的補給狀態多數情況沿用「完整」。

與要件 C 相乘的結果是：

> **任何營級單位都不可能滿足 W1，無論它被摧毀得多徹底。**

「禁止在屍體上收割殺傷分數」這條禁令，恰好對**最容易變成屍體的那一類單位**失效。

（敗方同時誠實註記：本案即使逐格計算，C 也會因事實而不成立
——紅軍從未進入 row 11 的 x ≤ 13。所以這是制度缺口，不是該方在本案的冤屈。）

### 待決修法（Run 6 前擇一或並行）

1. 為抽離的營級單位計算補給走廊（修 `compute_supply`）。
2. 要件 C 改為「無法脫離**或**無法作戰」（把 and 改成 or）。
3. 對某一規模以下的單位，C 改為可操作的判準：
   殘餘移動率低於攻擊方，或處於攻擊方火力範圍內且無脫離路徑。
4. 另立一條獨立禁令：對已無任何武器、且持續不還擊之編隊的持續砲擊。

**注意時序紀律**：本局已於 T0 凍結規則，故不得依此改判 Run 5。
修法自 Run 6 的 T0 前公佈後生效。

## 9.2 前進指揮所缺少「必須在前」的檢查

`command.delay_tier_adjust` 只檢查「軍長是否駐前進指揮所」與「距離是否 ≤ FWD_RANGE」，
**沒有任何「必須比本方主力更前」或「必須接近敵方」的條件**。

Run 5 藍軍因此把前進指揮所設在自己**後方縱深的森林格**（與主指揮所同格、三個營守備），
零斬首風險取得 0 級命令延遲。這使設計上原本要互相交換的「節奏優勢 ↔ 斬首風險」完全脫鉤。

本局已公開揭露、雙方皆可使用（紅軍隨後也設了一個，位置較誠實地在主力之前一格），本局不修。

待決修法：前進指揮所須位於本方主力重心之前，或距最近的已偵獲敵編隊若干格內。

## 9.3 觀測即開火權（裁示 56＋58）是一組極強的機制

- 裁示 56：砲兵不需自身視距內偵獲，該方**任一單位**偵獲即可射擊。
- 裁示 58：完全未偵獲者不得射擊，**本引擎無盲目彈幕／攔阻射擊**。

兩者相乘 → **打掉對方的觀測單位，等於讓其砲兵在師級視距（白天 3 格）之外失能。**
Run 5 紅軍 237 分全部來自這個機制的正確運用（把偵察隊釘在原地當觀測員，
讓後方推進中的師砲擊自己看不見的目標）。

已知缺陷：史實上 1944 年砲兵確實會對疑似位置實施攔阻與擾亂射擊，本引擎沒有。
待決修法：加入對格面射擊，效果按該格是否真有目標折算。

## 9.4 射程與機動的比例使開局幾何幾乎不可修正

全局白天 19 小時 × 步兵 0.67 格/hr ≈ **12 格**（一個師整局能走的總距離）。
砲兵射程 4–5 格。因此「防線設在哪一格」在尚未偵獲任何敵人的 T0–T4 就實質定案。

Run 5 敗方在 T6 才算出「我的砲兵打不到他停的那條線」，但剩餘白天只夠補回三分之一。

這在史實上合理（戰役部署確實不可逆），但它使本劇本獎勵**開局的幾何推算**
而非局中應變。待決：若希望局中判斷有更多權重，需調整機動速度與射程的比例。

## 9.5 工事分級（Run 5 新增）已驗證有效，但「移動即棄工事」讓調整陣地極貴

分級（無 0.70／淺掘 0.5hr → 0.40／散兵壕 3hr → 0.18／有頂蓋 8hr → 0.10）
搭配森林 ×0.7 相乘，使 Run 5 藍軍九個師級與營級編隊**全局零傷亡**。

但「移動或潰散即棄工事」（缺陷 13 的修正）使每一次調整陣地都要付 8 小時重挖的代價。
Run 5 藍軍兩次為了把砲兵射程推出去而放棄已挖滿的有頂蓋工事。
這個取捨是刻意的且雙方對稱，暫不修改，但須記得它與 9.4 相乘會進一步鎖死開局決定。
