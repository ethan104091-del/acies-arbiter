# 裁判裁示 — Run 6 第 8 號（T5 下令期間發布）

> 本文件對紅藍雙方逐位元組相同。
> **本裁示因一方提出規則未涵蓋之動作而作成，但兩軍自即刻起同等可用。**

## 裁示 17：偽裝作業（camouflage）

### 一、合法性 — 早已明定，不是新規則

《戰爭法》第 278 行載明：

> **夜襲、奇襲、偽裝、隱蔽、佯動** —— 合法戰爭詭計（ruse of war）。

此即海牙第四公約第 24 條「戰爭詭計……為合法」。偽裝**裝備種類、陣地、番號、兵力規模**
均屬合法詭計，不構成 W7 背信。W7 管的是**詐降與濫用休戰旗**；
偽裝成受保護身分（醫療、紅十字）亦屬背信，但本劇本無此類單位可偽裝（見《戰爭法》第 398 行）。

**結論：偽裝合法，一直都合法。** 本裁示不改變任何法律規則。

### 二、引擎能實作的部分 — 偽裝作業降低被偵獲的距離

新增 `camouflage()`，與構築工事完全對稱：

| 項目 | 內容 |
|---|---|
| 門檻 | **累計 3.0 工時** |
| 工時速率 | 與構築工事同表：工兵 1.5× ／步兵、裝甲 1.0× ／特戰、偵察、砲兵 0.67× |
| 前提 | 該 hour **未移動**，且須**明確下令「偽裝作業」**（比照裁示 33：固守不等於挖工事） |
| 效果 | 完成後，該編隊**靜止時的能見狀態好一級** |
| 失效 | **移動即失效並歸零**（同工事，帆布帶不走） |
| 開火 | 開火當小時仍為 EXPOSED（槍口焰、揚塵），但偽裝物留存，停火後恢復 |
| 工時池 | **與構築工事共用**——一小時只能擇一，不能同時挖洞又鋪偽裝 |

「好一級」沿用引擎**既有**的轉換表（特戰旅的滲透隱蔽用的就是這張），未新增任何係數：

| 原狀態 | 偽裝後 | 敵方須靠到幾格才發現 |
|---|---|---|
| STANDARD（開闊地靜止） | **CAMOUFLAGED** | **≤2 格** |
| CAMOUFLAGED | **CONCEALED** | **≤1 格** |
| CONCEALED | CONCEALED（已封頂） | ≤1 格 |

對照未偽裝時：STANDARD 與 EXPOSED 都是「進入視距即被發現」，
而視距為師 3／特戰 4／偵察 5（白天）。**偽裝可以讓你脫離既有的接觸。**

特戰旅的「好一級」與偽裝的「好一級」**可以疊加**，但封頂於 CONCEALED。

### 三、引擎做不到的部分 — 誤判為他種裝備

「讓敵方把戰車看成火砲陣地」**本局無法實作**，理由有二，且都是硬限制：

1. **戰報由程式產生，且報告真實編隊身分。** 要做誤判必須新增一套「假身分」機制，
   讓程式在敵方戰報中印出與事實不符的兵種。那是新的引擎機制，不是裁示。
2. **裁判不得手寫任何單方內容。** 這是 Run 5 查出的洩漏管道之一，已列為硬規則：
   單方事實只能經由**程式產生的戰報**送達。裁判若手打一份假情報進敵方資料夾，
   等於裁判可以任意寫入單方內容——那條路必須永遠封死，即使這次是為了執行一道合法命令。

**處置**：記入 `precedents.md`，作為 Run 7 是否引進「假身分／誘餌陣地」機制的待決議題。
本局不實作。

### 四、生效與追溯

本裁示**自發布時起生效，不追溯**。偽裝作業與其他命令一樣**吃命令延遲**
（主指揮所 +1 級）。任一方欲使用，須在命令中明確寫出「偽裝作業」四字並指名編隊。

### 五、為何這不違反規則凍結

《戰爭法》§0.1 規定規則於 T0 凍結、不溯及既往。本裁示不修改任何既有規則：
偽裝的合法性早已寫在規則裡，「好一級」的轉換表早已在引擎裡，工時速率沿用工事同一張表。
裁判在此做的是**對規則未涵蓋之新動作進行裁示**——那正是裁判存在的理由
（「引擎做不到」永遠不是拒絕裁示的理由；但「裁判不得手寫單方內容」是）。

兩軍自即刻起同等可用。
