# 裁判裁示 — Run 6 第 5 號（T3 下令期間發布）

> 本文件對紅藍雙方逐位元組相同。

## 裁示 9：手冊 §4 移動表與裁示 38 的牴觸 — 師級編隊不得入森林

**牴觸內容**：指揮官手冊 §4「移動」表列有「步兵師｜開闊地 0.67｜森林 0.33」，
讀來像是步兵師可以入林、只是慢一些。但 Run 5 的**裁示 38** 明定：

> 師級編隊的路徑**不得穿越森林**——其建制內的戰車營與牽引火砲在無路森林
> 是不可通行的。抽離的營級單位、特戰、偵察不受此限，照各自速率入林。

引擎自 Run 5 起即依裁示 38 執行：`infantry`、`armor`、`mech_inf` 三種**整編隊**
（非抽離營）一律不得進入森林格，尋路時會自動繞行。

**裁示**：以**裁示 38 為準**，手冊 §4 之表為誤植。正確讀法為——

| 兵種 | 開闊地 | 森林 |
|---|---|---|
| 步兵師（整編隊） | 0.67 | **不可入** |
| 裝甲師 / 自走砲（整編隊） | 1.00 | **不可入** |
| 裝甲步兵（整編隊） | 0.83 | **不可入** |
| **抽離之步兵營** | 0.67 | **0.33** |
| **抽離之裝甲步兵營** | 0.83 | 0.50 |
| 特戰旅（含其抽離營） | 1.00 | 0.50 |
| 偵察營（拉出） | 1.50 | 0.50 |

亦即表中「步兵師 森林 0.33」這個數字本身沒錯，但它適用的對象是**抽離的步兵營**，
不是整編師。想把兵力放進森林格的一方，必須先抽離營級單位。

**這不是規則變更。** 依《戰爭法》§0.1 規則於 T0 凍結；裁示 38 早於本局既已存在，
引擎自 T0 起亦一貫如此執行。本裁示只是更正手冊文字的誤導，不改變任何實際行為，
亦不影響已解算的任何一個 tick。

**發布理由**：本 tick 有一方在下令時遭遇此牴觸並向裁判提出。由於這是**規則層面的
誤導**（不是任何一方的位置或意圖），對雙方同等重要，故以公開裁示同步發布，
而非依裁示 7 只送交單方。

## 裁示 10：附帶澄清 — 工事不影響「是否被發現」

構築工事降低的是**暴露係數**（該編隊被命中時的傷害倍率，手冊 §11 的分級表），
**不改變其能見狀態**（EXPOSED / STANDARD / CAMOUFLAGED / CONCEALED，手冊 §6）。
在開闊地靜止的編隊即使挖到有頂蓋級，仍然是 STANDARD——敵方視距內即被發現。

隱蔽靠地形與兵種（森林、特戰旅的「永遠好一級」），不靠工事。兩者互不替代。
