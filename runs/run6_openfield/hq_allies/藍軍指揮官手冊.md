## 0. 你必須知道的三件事

1. **你只看得到偵察範圍內的敵軍。** 戰報裡沒出現的敵單位，代表你現在不知道它在哪——不是它不存在。
2. **命令有延遲。** 你這個 tick 下的命令不會立刻生效（見 §5）。你在對「6 小時後的戰場」下令。
3. **勝負是殲敵計分＋斬首。** 不佔地、不守點。詳見 §3。

## 1. 戰場

- 30×18 格，每格約 2 km。座標 (x, y)，**x 向東遞增、y 向南遞增**。
- 地形：約 95% 開闊農地，零星小林叢（地圖上標 `林`）。**180° 旋轉對稱，雙方地形絕對公平。**
- 森林效果：守方戰力 ×1.5、攻方 ×0.7；**戰車與牽引砲不可進入森林**（本圖無道路）；步兵可入但慢。
- 開闊地無任何天然掩體——**沒有地形可躲。偵察、節奏、欺敵、補給勒殺才是全部。**
- 天氣：全程晴好，無雲雨影響，無空中支援（本劇本雙方皆無航空兵）。
- 日夜：06:00–18:00 白天；夜間**移動速度減半、偵察視距縮短**（見 §4、§6）。

## 3. 勝負條件

1. **斬首即勝（立即結束）**：敵方戰鬥單位**佔領你軍長當前所在的指揮所格**→ 你**立即落敗**。反之亦然。
2. **殲敵計分（撐到 Tick 8 結束）**：分數 = 你造成敵方的 **人員傷亡 ×1 + 擊毀戰車 ×20 + 擊毀火砲 ×10**。高者勝。
3. **平手**：殲敵相當時，自損較少者勝。

> 沒有地形目標、沒有城鎮可佔。這是純粹的殲滅戰，時間上限逼雙方必須交戰。

## 5. 指揮所、命令延遲、斬首 ★本劇本核心

**開局你沒有任何指揮所**，軍長隨部隊臨時指揮 → **命令延遲吃 +2 級（最慢）**。

| 狀態 | 命令延遲 | 斬首風險 |
|---|---|---|
| 未建指揮所 | **+2 級**（L1→3hr、L2→4hr、L3→5hr） | 無固定目標、不可被斬 |
| **主指揮所**（通常設後方） | **+1 級**（L1→2hr） | 是斬首目標，但可設在深遠後方＝極難摸到 |
| **前進指揮所**：其**周圍 6 格內**的單位 | **基準**（L1=1hr、L2=2hr、L3=3hr） | 是斬首目標、靠前易被斬 |

- 下令建立指揮所 → **架設 2 小時**才生效，生效時軍長進駐。
- 軍長同時只在一個指揮所裡。可同時擁有主＋前進兩個；**軍長在哪個，哪個才是斬首目標**。
- 移動軍長／換位＝重新架設 2 小時，期間退回 +2 級延遲。
- **敵人不會自動知道你的指揮所在哪**——他要靠偵察摸出來（他的特戰旅就是幹這個的）。你也一樣。
- 「乾脆不建指揮所」不划算：吃最慢延遲＝放棄指揮靈活度。**這是真實軍長的取捨。**

命令等級由你自己選：**L1 = 緊急/簡單動作**、**L2 = 標準機動**、**L3 = 複雜協同（多編隊配合、大規模轉向）**。
等級越高延遲越久，但複雜行動硬報 L1 裁判會駁回（不合理）。

## 6. 偵察與能見（無擲骰，全部確定性）

**你的單位視距**（切比雪夫距離，白天/夜間）：師級主力 **3/2**；特戰旅 **4/3**；拉出的偵察營 **5/3**。

**目標的能見狀態**由它自己的處境決定（裁判每 hour 自動計算，雙方同一套）：

| 狀態 | 何時進入 | 被發現條件 |
|---|---|---|
| EXPOSED 暴露 | 該 hour 開火／在開闊地移動 | 進入視距即被發現 |
| STANDARD 標準 | 在開闊地靜止 | 進入視距即被發現 |
| CAMOUFLAGED 偽裝 | 在森林移動／進森林未滿 2hr | 只有**≤2 格**才被發現 |
| CONCEALED 隱蔽 | 在森林靜止滿 2hr | 只有**≤1 格**才被發現 |

**特戰旅永遠好一級**（滲透隱蔽）：開闊靜止=CAMOUFLAGED、開闊移動=STANDARD、森林靜止2hr=CONCEALED。
→ 這代表**特戰旅在開闊地都不容易被遠距發現**，是它能滲透縱深的原因。

**指揮所徵候**：敵單位靠到**2 格內（夜 1 格）**才會看出「這裡是指揮所」。一旦被看到就永久記錄。
你的戰報「敵情」欄只列你**現在**偵獲的敵軍；失去接觸的敵軍會消失（你要自己記筆記推斷它去哪了）。

## 7. 補給（可被勒殺）

- 你的補給源＝**西緣 x=0**。每個編隊的**補給走廊**＝從它現在位置沿同一橫排(y)拉回你的邊緣那一串格。
- 三態：**暢通 100%**（走廊旁無敵）／**受威脅 50%**（敵距走廊 1 格）／**切斷 0%**（敵戰鬥單位站在走廊上、擋在編隊與補給源之間）。
- 每個 tick（6hr）結算一次補給：暢通 → POL/SA/HE/AT/RAT 各 +22%、MED/PARTS +10%；受威脅減半；切斷 = 完全沒有。
- 每 hour 消耗（步兵師基準，%）：駐紮 POL0.3；行軍 POL2.0；戰鬥 POL2.5/SA2.0/HE1.5/AT1.5；重戰鬥 POL4/SA4/HE3.5/AT4。
  **裝甲師 POL ×3.0、AT ×2.5、PARTS ×2.0、HE ×1.5。**
- 危機閾值：POL<20% 移動半速、<10% 停擺；SA<30% 戰鬥 -30%；HE<30% 砲擊 -30%；AT<30% 反裝甲 -40%；RAT<30% 組織度上限 -10。

→ **裝甲師滿油約可連續機動 16 小時（不到 3 個 tick）。深遠突穿必須算油。**
→ 把敵編隊的補給走廊坐死，比正面硬打便宜得多。這是本劇本的招牌殺法之一。

## 8. 戰鬥怎麼算（你可以自己預估，裁判照同一套算）

戰鬥力 CP = 基礎值 × 戰力% × 組織度/100 × 補給係數 × 經驗倍率 × 地形倍率 × 能見倍率 × 兵種協同 × 戰術狀態

- 基礎值：步兵師 100、裝甲師 150、特戰旅 45（旅級規模）。
- 經驗：標準 ⭐⭐⭐=1.0、老兵 ⭐⭐⭐⭐=1.15、精銳 ⭐⭐⭐⭐⭐=1.30（**特戰旅=1.30**）。
- 地形（守方/攻方）：平原 1.0/1.0、森林 1.5/0.7。已挖工事守方 +0.5（需 4-6hr 構築）。
- 能見：**攻方沒發現守方 → 守方伏擊 ×2.0**；**守方沒發現攻方 → 攻方突襲 ×1.5**；互見 1.0。
- 兵種協同：單一兵種 1.0、雙兵種（步+戰、戰+砲、步+砲）1.3、三兵種 1.5、四以上 1.7。
  → **同一格或相鄰格有你的砲兵/裝甲一起打，加成很大。單獨一個師硬撞會吃虧。**
- 戰術狀態：突襲 攻×1.5守×0.7、預設陣地 1.0、被動應戰 守×0.85、從行軍中接戰 該方 ×0.7、突破後追擊 攻×1.4守×0.6。

**兵力比 → 每 hour 損失**（Force Ratio = 攻方CP / 守方CP）：

| 兵力比 | 攻方 | 守方 | 位置 |
|---|---|---|---|
| <0.5 | -4% 戰力、-12% 組織 | -0.5%、-2% | 攻方被迫後退 |
| 0.5-1.0 | -3%、-10% | -1%、-4% | 原地 |
| 1.0-1.5 | -2%、-7% | -2%、-7% | 原地 |
| 1.5-2.0 | -1.5%、-5% | -3.5%、-12% | 守方後退 1 格 |
| 2.0-3.0 | -1%、-3% | -6%、-20% | 守方後退 2 格 |
| 3.0-5.0 | -0.5%、-2% | -10%、-30% | 守方潰散風險 |
| >5.0 | -0.5%、-1% | -15%、-40% | 守方必潰散 |

（這是**每 1 hour** 的損失，多小時交戰累積。戰力% 損失同步換算成人員傷亡與裝備損失。）

**戰車對戰車**：雙方都是 1944 中戰車，正面互穿（無 Panther 級怪物）。每輛每 hour 約 13 發，命中係數：雙方移動 0.06、攻動守靜 0.10、攻靜守動 0.13、雙方靜止 0.15、hull-down 0.18。→ **靜止防禦的戰車命中率比衝鋒的高。**
**砲兵**：105mm 有效射程 8.5km（≈4 格）、155mm 11.5km（≈5 格）；砲擊開闊地散開步兵每發 0.21 人，工事內 ×0.1。**砲兵是本劇本最穩定的傷害來源，但開火會讓自己 EXPOSED。**
**潰散**：組織度<25 且 24hr 內傷亡>30% 且退路被切 → 潰散，強制後退 2-3 格、可被追擊（傷亡 ×3）。

## 10. 開局提示（雙方相同）

- 開局**無指揮所**＝所有命令 +2 級延遲。第一件事通常是決定指揮所位置與是否前推。
- 雙方初始部署是 **180° 旋轉鏡像**：你有 3 個步兵師沿你的邊緣、裝甲師在中路後方、特戰旅在一角。
  → 你可以合理推斷敵方**開局**的大致部署（就是你自己的鏡像），但他一旦動了，你就只能靠偵察。
- 距離很遠（東西相隔約 25 格）：主力接觸大約要 1-2 個 tick。這段時間是佈局與偵察的黃金期。

# ★ Run 5 新增規則（Run 4 沒有的部分，全部對雙方對稱生效）

## 11. 工事分級（改動）

Run 4 是一道命令挖 2.7 小時就吃滿。現在分級，而且**第一鏟土買到的防護最多**：

| 級 | 累計工時 | 砲擊暴露 | 戰車暴露 | 組織度衝擊減半 | 說明 |
|---|---|---|---|---|---|
| 無工事 | — | 0.70 | 0.30 | 否 | 開闊地散開 |
| **淺掘** | 0.5hr | **0.40** | 0.15 | 否 | 臥射掩體，擋破片不擋近失彈 |
| **散兵壕** | 3hr | **0.18** | 0.05 | **是** | 標準散兵坑，可站立射擊 |
| **有頂蓋** | 8hr | **0.10** | 0.05 | 是 | 完整掩體，擋空爆與樹爆 |

- 工時速率：工兵 1.5×／步兵與裝甲 1.0×／特戰、偵察、砲兵 0.67×（人手少）。
- **必須明確下令構築**。「固守」「戰備」「防禦姿態」都不是構築工事（裁示 33）。
- 該 hour 有移動就不累積工時；**移動或潰散即棄工事**，挖好的洞帶不走。
- 半小時的淺掘就把砲擊傷亡砍掉四成強；但要拿到「組織度衝擊減半」與戰車掩壕，
  得挖到散兵壕級（3hr）。完整掩體是 8 小時的重投資。

## 12. 組織度（org）：崩潰是真的會發生

組織度低到門檻，你的編隊會**潰散**甚至**自行投降**。Run 4 全程沒有人崩，是因為
當時的解算只算了組織度損失公式的第一項。現在六項全部生效：

```
每 hour 組織度衝擊 = ( 本 hour 傷亡% × 1.5
                    + 連續戰鬥滿 6hr 起，每 hour 額外 2
                    + 被突襲 10
                    + 指揮所被毀 20 ／ 團長陣亡 5
                    + 誤擊 10 )
                    × ( 挖到散兵壕級以上 ? 0.5 : 1 )
每 hour 自然恢復 = 補給線完整時 +1
```

**潰散（三條同時成立）**：組織度 < 25、24 小時內傷亡 > 30%、退路被切斷或指揮鏈中斷。
→ 狀態變 `ROUTED`、**強制後撤**、棄工事、**撤退途中被追擊者傷亡 ×3**。
　6 小時後補給恢復可收攏（組織度回到 30）；12 小時未收攏則解散。

**追擊潰散部隊完全合法**（見 §16.4 明文合法）。潰散不等於投降。

## 13. 投降有兩條路

| | 觸發 | 你的控制權 | 能不能用來詐降 |
|---|---|---|---|
| **自行投降** | 組織度 < 15 **且**（被四面包圍／連續 48hr 無補給／食物 <5% 且戰役 >7 天） | **失去** ——該編隊不再接受命令、不移動、不開火 | 不可能 |
| **手動示降** | 你下令，**無任何門檻、隨時可下** | 保留 ——仍可被你命令行動 | 可以（就是 §16.1 的 W7） |

兩條路都**不可逆**。已投降的編隊**不得主張防禦戰力**（防禦時戰力歸零）。

**對手可以選擇不受降。受降從來不是義務。** 受降必須明確下令，裁判絕不代為執行。

**命令格式（機器解析，不經裁判文字解讀）**
```
示降 BLU-1
受降 RED-2
受降 RED-2 BY BLU-AD      ← 指定由哪個編隊執行受降
```
- 走命令延遲（同其他命令）。**信號中斷的編隊收不到示降令** —— 那時要投降只能靠自行投降。
- 文字裡有「投降／白旗／繳械／請降」但不符上列格式者，**不會自動執行**，
  會被記成「命令待裁」並回報你格式。這是為了讓歧義浮出來，而不是由裁判替你解讀。

**受降有成本**：俘虜計入你的殲敵分數（與陣亡同權），但你要用自己的口糧餵他們
（每 hour 扣 RAT），並抽出約 5% 俘虜數的兵力看管後送（那些人不算傷亡，但不能作戰）。
所以大規模受降是把後勤負擔接到自己身上 —— 這正是史實上大規模投降的作戰效果。

**不投降而戰至全滅完全合法**，不構成任何罪名。

## 14. 通訊

- **命令延遲**取決於指揮所：前進指揮所罩內 0 級／有主指揮所 +1／無指揮所 +2，
  再加命令本身的 L1/L2/L3 基準。**距離會影響**（前進指揮所有作用半徑）。
- **信號中斷**：一個編隊同時「補給走廊被切斷」且「四面被包圍」→ 與你失聯。
  效果是**新命令送不進去**，不是失去戰力 —— 它會繼續執行最後一道既有命令。
- 前進指揮所因此買到三件事：機動節奏、更快的示降／受降、以及**更短的法律免責期**（§16.2）。

# 16. 戰爭法與軍事法庭（★本局新設，T0 前公佈）

## 16.0 三件最重要的事

1. **戰局之內只有事實。** 裁判在局中**不判**任何行為違法，程式也不判。
   合法與否是**戰後法庭**的辯論。你在局中不會收到「你這樣違法」的警告。
2. **只有敗者受審。** 勝者不受起訴（無例外），但罪行仍列入戰史為「未受審之罪行」；
   若重播證明該罪行是勝因，勝利降格為「有瑕疵之勝利」。
3. **起訴權在你手上。** 終局後你可以起訴對手，但**只能用你自己合法取得的情報**舉證。
   誤告會被駁回並記入紀錄，降低你後續對局的申辯權重。裁判不主動起訴。

**法源只用 1944 年當時已生效的法**：1907 海牙第四公約附件、1929 日內瓦戰俘公約、
1925 日內瓦毒氣議定書。戰後才出現的規範（1949、1977、1980）一律不適用。
**本表未列的行為即為合法。** 本表在 T0 前公佈，其後只適用、不新增、不修改。

## 16.1 生效的三條罪名

### W1 — 攻擊已喪失戰鬥力之編隊
> 海牙第四公約第 23 條(c)：禁止殺傷已放下武器、或已失去自衛手段而投降之敵

三項要件**同時**成立，該編隊即為已喪失戰鬥力：

| | 要件 |
|---|---|
| A | 累計傷亡 ≥ 建制 70%；**或** 傷亡 ≥ 50% 且組織度 ≤ 25；**或** 火砲與戰車同時歸零且傷亡 ≥ 50% |
| B | 前一小時未實施任何攻擊，且（火砲存量 0 **或** 補給切斷） |
| C | 補給走廊切斷 |

**合法替代手段：停火並維持包圍／接觸。** 該編隊已無法作戰、補給、脫離，
圍而不打不損失任何作戰利益。所以 W1 禁止的不是取勝，而是**在屍體上收割殺傷分數**。

### W2 — 不受降、屠殺已投降之編隊
> 海牙第四公約第 23 條(c)、1929 日內瓦戰俘公約

- **W2a**：對已投降（兩條路皆同）的編隊，於明知並經寬限期後繼續攻擊。
- **W2b**：已繳獲的俘虜其後從人員帳中消失而無合法解釋。

**可信度**：對手不信是否合理，由法庭依示降當時的客觀狀態認定 ——

| 示降當時 | 敵方繼續攻擊 |
|---|---|
| 符合 §13 的四條件（組織度 <15 且被圍／斷補／斷糧） | 構成 W2 |
| 不符合（例如滿編師舉白旗） | **合法** ——合理不信任 |

可信度按各時點分別認定：示降當時不可信、其後真的被打崩了 → 停火義務自那時起發生。

**受降方的自保是合法的**：可要求示降編隊主動離開陣地、繳出重裝備、向你指定位置
徒步集中。你**沒有義務**前進接收、沒有義務離開工事、沒有義務停止對**其他**編隊的火力。
對拒絕執行受降程序的編隊恢復攻擊，不構成 W2。

### W7 — 詐降（背信）
> 海牙第四公約第 23 條(f)：禁止不當使用休戰旗

已宣告示降的編隊，於敵方停火或前進受降後實施任何攻擊動作。
**只可能經手動示降發生**（自行投降者已脫離你的指揮，不可能被命令開火）。

- 罰分為不法收益的 **×3**（其餘罪名 ×2）。
- 示降編隊一旦開火，法庭將認定其停火主張自該時點起失效、且不適用寬限期。
- **代價不由規則執行，由對手執行**：對手看過一次詐降之後會不會再受降，是他的判斷。
  後果落在你全軍 —— 你所有陷入絕境的編隊從此可能只能戰至全滅。

## 16.2 明知與寬限期

- **明知**：戰報向你顯示過該狀態才算。戰報只在**持續接觸滿 2 小時**（你正在射擊它，
  或連續 2 小時在你視野內）才顯示對方的「戰鬥力狀態」欄。沒顯示 → 過失，不起訴。
  （示降是對敵宣告，所以**無條件顯示**，不受 2 小時限制。）
- **寬限期 = 你自己的命令延遲時數**。理由是對你無力阻止之事不負責任：停火命令傳達需要
  時間，那段時間就是你的免責期。**前進指揮所因此縮短你自己的免責期。**

## 16.3 空條文與不適用

- **W3 強制審訊俘虜**：規則裡沒有可下的審訊命令，故為**空條文，不得追訴**。
- **W4 對留城平民重砲／W5 徵用平民／W6 白磷射入平民區**：純戰場地圖無平民，**不適用**。
- **「整師指揮官陣亡＋信號中斷」這條投降條件是空條件**：本引擎無幹部傷亡模型，
  而斬首是即時勝利、遊戲會直接結束。

## 16.4 明文合法（不得以任何名義追訴）

- 攻擊敵指揮所、斬首作戰。
- 切斷補給走廊、圍困使其耗盡。
- **追擊潰散部隊，含傷亡 ×3 的追擊倍率。** 潰散不等於投降：潰散部隊仍在移動、
  仍可能重整，未失去自衛手段。**追殺逃兵合法，砲擊已癱瘡的殘部才是罪。**
- 砲擊仍有戰鬥力的編隊，無論其是否構築工事、無論傷亡多寡。
- 夜襲、奇襲、偽裝、隱蔽、佯動（合法戰爭詭計）。
- 在對方尚有還擊能力時的全滅性攻擊。
- 對戰鬥員使用白磷（1944 年無條約禁止）。

## 16.5 量刑怎麼算

零擲骰、每 tick 有快照，所以法庭可以計算反事實：

```
把違法動作換成該罪名的合法替代 → 從該時點的快照重播到終局
不法收益 = 實際分數 − 反事實分數
罰分 = 不法收益 × 2（W7 為 ×3）
```

判決書會載明兩個分數與差額，任何人都能用快照重跑驗證。

# ★★ Run 6 規則修正（依 Run 5 的判例，T0 前公佈，其後凍結）

Run 5 終局 **紅軍 237 : 藍軍 171**，54 小時、雙方主力零接觸、零地面戰、零戰車損失，
408 分全部來自彼此的偵察幕。覆盤查出的三項缺陷已修正如下。
Run 5 的完整戰史（終局總結、事實紀錄、敗方覆盤）已同時放進雙方資料夾，兩份相同。

## 修正 A — 抽離的營級單位現在會計算補給走廊

`compute_supply` 原本跳過所有抽離的營級單位，使其補給狀態永遠沿用「完整」。
與 W1 要件 C（補給走廊切斷）相乘的結果是：**任何營級單位都不可能滿足 W1**，
不論它被摧毀得多徹底。「禁止在屍體上收割殺傷分數」恰好對最容易變成屍體的
那一類單位失效。**現已修正：抽離營與師級一樣逐格計算走廊。**

**W1 的三要件本身不變**（維持 A 且 B 且 C）。Run 5 敗方在覆盤中主張要件 C 是對的：
W1 的合法替代是「停火並維持包圍」，其正當性正是該編隊**無法脫離**；
一個能撤走的單位不是屍體。裁判接受此論證，故不放寬要件 C。

## 修正 B — 前進指揮所必須「真的在前」

原本只檢查「軍長是否進駐」與「距離 ≤ 6 格」，**沒有任何位置要求**。
Run 5 有一方因此把前進指揮所設在自己**後方縱深的森林格**（重兵守備），
零斬首風險取得 0 級延遲——使「節奏優勢 ↔ 斬首風險」完全脫鉤。

**新判準**：前進指揮所須位於**本方各作戰編隊 x 座標的中位數之前**（朝敵方補給源的方向）。
藍軍補給源在西緣 x=0，故「前」＝ x 較大；紅軍相反。不滿足者不給 0 級，退回 +1 級。

用「自己部隊的中位數」而非「距敵方多近」，是因為後者依賴戰霧
（雙方看到的敵情不同 → 判準不對稱）；中位數是雙方都能自行驗算的客觀量。

## 修正 C — 新增「攔阻射擊」：可以對格面開火，不需偵獲

Run 5 的裁示 58 是「完全未偵獲者不得射擊」，因為引擎只能對「目標編隊」開火。
後果是**打掉對方的眼睛比打對方主力更有效率**（Run 5 勝方 237 分全來自此機制）。
但史實上 1944 年砲兵確實會對疑似位置實施攔阻與擾亂射擊，所以那是引擎缺陷。

**新規則**：可以指定**一個格子**實施攔阻射擊，不需該格有已偵獲的敵編隊。

| | |
|---|---|
| 命令寫法 | `攔阻射擊 (x,y) BY <編隊>`（可多個編隊，逗號分隔） |
| 效果 | 若該格確有敵編隊 → 照常解算，但**每發殺傷力 ×0.30**（無觀測校射） |
| 該格無敵編隊 | 效果為零，**彈藥與暴露照付** |
| 代價 | 開火方該小時一律標記為**已開火 → EXPOSED**（暴露自己的位置） |

所以攔阻射擊適合壓制與擾亂，不適合當主要殲敵手段；而且它會讓你的砲兵被看見。

**對戰爭法的影響**：裁示 58 的「本局無盲目彈幕」自 Run 6 起**失效**。
但 W1／W2 的**明知**要件不變——你若主張對手違法，仍須證明戰報向其顯示過該狀態。
反面：對一個你**未偵獲**的編隊實施攔阻射擊而恰好命中，因為你不明知，**不構成 W1**。
