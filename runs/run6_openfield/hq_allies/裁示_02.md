# 裁判裁示 — Run 6 第 2 號（T1 下令前發布）

## 裁示 3：常設命令的效力與延遲

**問題**：換一個 tick 時，上一個 tick 的命令還算不算數？不重新下令會怎樣？

**裁示**：**命令是常設的（standing orders）。** 一道命令一旦生效，就持續執行到
「完成」、「被新命令取代」或「該編隊失去執行能力」為止，不因換 tick 而失效。
手冊 §5 在信號中斷一節寫「它會繼續執行最後一道既有命令」，該句所描述的是命令的
一般性質，不是信號中斷時的特例。

由此推出兩件對雙方同等成立的事：

1. **不下新命令＝零延遲。** 若你這個 tick 想做的事，上一個 tick 的命令已經涵蓋，
   你不必重下；部隊自該 tick 第一小時（gh6、gh12、…）起即繼續執行，不吃任何延遲。
2. **下新命令＝該命令從頭吃一次完整延遲**，且新命令取代它所涵蓋的舊命令。
   只想改一個編隊就只下那一個編隊的命令，其餘編隊的舊命令不受影響。

**應變條款同樣是常設的**，不重錄也繼續生效。重錄不會產生額外效果，也不會產生額外延遲。

**發布理由（裁判過失）**：本裁示的內容，裁判在 T1 下令階段**主動向藍軍指揮官說明過，
卻未同時向紅軍說明**。這是一次不對稱的規則指導——雖然內容本身兩方的手冊都有，
但由裁判主動點破與否，構成了不該存在的差別待遇。裁判在藍軍的 T1 命令定稿後、
紅軍開始下令**之前**發現此事，故以本裁示同步補正，兩軍在下 T1 命令時掌握的
規則資訊因此完全一致。

紅軍在讀到本裁示後，若欲據此調整其 T1 命令的下法（例如改為不重下命令以省去延遲），
一律准許，不視為逾時。
