# 裁判裁示 — Run 6 第 13 號（T7 下令期間發布）

> 本文件對紅藍雙方逐位元組相同。

## 裁示 26：更正 — 裁示_11 之裁示 23 誤載

**原文（裁示_11，裁示 23）**：
> 本次砲擊的完整算式已載於**雙方**戰報，此處只陳述規則層面的事實：

**更正為**：
> 本次砲擊的完整算式**僅載於開火方之戰報**。目標方之戰報只載其自身傷亡與組織度變化，
> **不含距離、發數、每發殺傷力**。

**成因**：引擎的 `bombard()` 將射擊明細字串寫入**開火方**的日誌，
目標方的日誌只有傷亡結果。裁判在撰寫裁示_11 時未查證即寫成「雙方戰報」。

**此一不對稱本身是合理的**——開火方當然知道自己打了多遠、用了幾門砲；
目標方能取得的只有裁示 25 明定的方位與口徑。
錯的是裁判對現況的描述，不是現況本身。

**影響**：無。裁示 23 的實質內容（工事分級對傷亡的倍率）不受影響，
該段的數字全部來自手冊 §11 的公開表格，兩方本就同等可算。

## 裁示 27：裁判拒答之事項，及其理由

本 tick 有一方就**其自身所受砲擊是否已因射程而衰減**向裁判提問。
**裁判拒絕回答**，理由記載於此，對雙方同等適用：

1. **該數值不在提問方的戰報中**（見裁示 26）。裁判於對話中告知，
   等同以手寫方式向單方交付事實——那是 Run 5 查出的洩漏管道，已列為硬規則：
   **單方事實只能經由程式產生的戰報送達，無例外。**
2. **其答案即為距離資訊**，而距離是裁示 25 明文排除的項目。
   回答等於從後門推翻自己數分鐘前發布的裁示。
3. 基於同一理由，裁判**亦不公布傷害公式的完整常數**
   （每次火力任務的發數、密度係數分級）。公布之即可由自身傷亡反算敵砲距離，
   效果與直接回答相同。

**裁判在此承認該提問背後的物理論證是對的**：閃光到聲響的時間差可直接測距，
不需要觀測營編制；裁示 25 排除距離的理由過嚴。
**但裁判不會因一方提問而在局中推翻自己的裁示**，尤其在其足以決定勝負之時。
`law_of_war.md` §0.4 已定：規則修訂只能在兩局之間，自下一局 T0 起生效。

此項已記入 `precedents.md` §十一，作為 Run 7 的修訂項目。
Run 7 的建議方向是：**手冊於 T0 即公布完整傷害公式與全部常數**，
並同時給予 flash-to-bang 的粗略距離帶——資訊透明與現實能力兩者一致。

**對雙方的意義相同**：本局之內，你能取得的敵情就是你的戰報所載的，
不多也不少。裁判不會因為你問得有道理就多給你一點。
