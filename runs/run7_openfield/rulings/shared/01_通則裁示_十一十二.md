### 裁示 52：CP 算式沒有「能見倍率」這張表——手冊寫錯了

手冊 §8 把 CP 算式列為:

```
CP = 基礎值 × 戰力% × 組織度/100 × 補給係數 × 經驗倍率
     × 地形倍率 × 能見倍率 × 兵種協同 × 戰術狀態
```

其中「**能見倍率**」的寫法會讓人以為有一張
EXPOSED／STANDARD／CAMOUFLAGED／CONCEALED 對應不同數值的表。**沒有那張表。**
這是手冊的措辭錯誤,裁判承認。

引擎(`arbiter.unit_cp`)裡與能見有關的只有**一條,而且是二元的**:

```
若（該編隊是守方）且（攻方未偵獲它）→ CP × 2.0     # 伏擊
否則                                → CP × 1.0
```

**沒有中間值。** 被發現就是 ×1.0,沒被發現就是 ×2.0。

#### 那能見狀態還有什麼用

有用,而且用處很大——它決定**你會不會被偵獲**,也就決定上面那個 ×2.0 適不適用:

| 能見狀態 | 被發現的條件 |
|---|---|
| EXPOSED／STANDARD | 進入敵方視距即被發現（師 3 格、特戰 4、偵察 5;夜間各減） |
| **CAMOUFLAGED** | 只有 **≤2 格**才被發現 |
| **CONCEALED** | 只有 **≤1 格**才被發現 |

所以偽裝在近戰裡的價值是**全有全無**的:它不會讓你的 CP 多 10%,
它讓你在敵人踏進 2 格之前完全不存在,而一旦對方在未偵獲的情況下發起突擊,你的 CP **加倍**。

#### 順帶：CP 的完整乘數清單（以引擎為準，補齊手冊漏列的兩項）

| 乘數 | 值 | 適用 |
|---|---|---|
| 基礎值 | 步兵 100／裝甲 150／特戰 45／抽離營 人數÷1000×7.1 | 全部 |
| 戰力% | strength/100 | 全部 |
| 組織度 | org/100 | 全部 |
| 補給係數 | 依補給走廊 | 全部 |
| **經驗倍率** | 1★0.75／2★0.85／3★1.0／4★1.15／**5★1.3** | 全部 |
| 疲勞 | 60–80 ×0.9／80+ ×0.8 | 全部 |
| 地形 | 攻方入林 ×0.7；**守方**林 ×1.5、開闊 ×1.0 | — |
| 工事 | **加**在守方地形倍率上（`地形 + fortification`，最高 +0.5） | 守方 |
| 伏擊 | ×2.0（攻方未偵獲守方） | 守方 |
| 兵種協同 | 1 種 1.0／2 種 1.3／**3 種以上 1.5** | 全部 |
| 從行軍中接戰 | ×0.7 | 攻方 |
| **被動防禦** | **×0.85** | 守方（未主動出擊時） |

**手冊漏列了「經驗倍率」的實際數值與「被動防禦 ×0.85」。** 兩者現予補正。
特戰旅 5★ 的 1.3 倍是全軍最高——這是它在 Run 6 幾乎沒被用到的價值。

### 裁示 53：裁示 47 與裁示 32 不矛盾，因為突擊本身不算「移動過」

有指揮官指出:裁示 47 說「移入敵佔格是**近戰突擊、不是移動**」,
而裁示 32 的 ×0.7 判準是「該編隊**該小時是否實際移動過**」。
字面上一個說不是移動、一個問有沒有移動,像是矛盾。**實質不矛盾。**

查引擎:`arbiter.battle()` **只讀取** `flags["moved"]`,**從不設定它**。
設定 `moved` 的只有 `advance()`。而依裁示 47,裁判解算突擊時**不呼叫 `advance()`**。

因此:

| 該小時的情形 | `moved` | 從行軍中接戰 |
|---|:---:|---|
| 該小時一路行軍、抵達敵格旁後隨即突擊 | **True** | **×0.7** |
| 該小時原地未動（已在敵格旁），發起突擊 | **False** | **不罰** |

**這正是規則要表達的東西,不是漏洞。** 走了一整個小時的部隊,隊形是行軍縱隊、
砲兵還在後面、無線電還在架——它撞上去當然比不上一支已經展開、標定完成的部隊。

由此可以自己算出來的取捨:**在敵格旁停一小時,買到攻方 CP 提高 1/0.7 ≈ +43%,
代價是給對方一小時。** 那一小時對方可以拿去挖工事(暴露 0.70→0.40 只要半小時)、
呼叫砲兵、或是撤走。這筆帳雙方自己算,裁判不代為權衡。

**補充兩點,以免誤解:**

1. 突擊該小時,攻守雙方都會被標記為 `fired`(地面戰即交火),
   因此**該小時都不能再實施間接火力任務**,而且都轉為 EXPOSED。
2. 守方仍享 `passive ×0.85`——除非它同一小時也對別處發動了主動攻擊。
