## 裁示 56–57（T1，通則，雙方拿到完全相同的內容）

---

### 裁示 56：近戰 CP 相加。守方全格自動參戰，攻方必須受命

`arbiter.battle()` 的算式:

```
a_cp = Σ 攻方各編隊的 CP
d_cp = Σ 守方各編隊的 CP
```

**兩邊都是相加。** 但「誰被算進去」攻守不同:

#### 守方：該格所有具作戰能力的編隊，全部自動參戰

你不能在一個正被突擊的格子裡宣稱自己沒參戰。同格的每個編隊——
包括抽離的砲兵營、偵察營、工兵營——**一律計入守方 CP,也一律承受守方損失**。
這與裁示 48(砲擊時同格全部承受)是同一個原則:**格子是一塊地,不是一份名單。**

已投降的編隊不計(放下武器不能再主張抵抗);潰散中的仍計(它還在那塊地上)。

#### 攻方：只有你明文下令突擊的編隊才參戰

不會有部隊被「捲進」一場它沒被命令參加的攻擊。要多個編隊協同突擊同一格,
就在命令裡把它們都寫出來。

#### 由此得出一個不明顯但重要的後果：兵種協同的範圍比你想的大

`COMBINED` 依**兵種數**計算(1 種 1.0／2 種 1.3／**3 種以上 1.5**)。
而 `arbiter.arms_present` 統計的範圍是:

> **參戰的編隊,＋該方位於戰鬥格「相鄰 8 格以內」的所有編隊。**

也就是說,**沒有參戰、只是站在旁邊一格的友軍,也會把它的兵種帶進協同倍率。**
砲兵營擺在戰鬥格旁邊一格,即使它該小時沒開火,也讓突擊方多一個兵種。

各兵種提供的「兵種」如下(`ARM_OF_TYPE`):

| 編隊型別 | 計入的兵種 |
|---|---|
| 步兵師／步兵營 | 步兵、砲兵、戰車（**三種,單獨一個就滿額 1.5**） |
| 裝甲師 | 戰車、砲兵、裝步（**三種,單獨一個就滿額**） |
| 特戰旅 | 特戰、迫砲（兩種 → 1.3） |
| 抽離的偵察營 | 偵察（一種） |
| 抽離的工兵營 | 工兵（一種） |
| 抽離的砲兵營 | 砲兵（一種） |
| 抽離的裝甲步兵營 | 裝步（一種） |

**注意這裡的不對稱:** 一個**整編**步兵師或裝甲師自己就佔三個兵種,協同已滿 1.5,
再加友軍也不會更高。但**抽離出來的營各自只佔一個兵種**——
四個步兵營疊在一格是 {步兵、砲兵、戰車}(它們仍算 infantry 型別)= 1.5;
四個偵察營疊在一格則只有 {偵察} = 1.0。

**所以拿營級單位守關鍵格時,兵種搭配會直接改變 CP 五成。** 雙方自行運用。

### 裁示 57：雙方同時移入對方所在格 —— 遭遇戰

引擎裡**沒有同時性模型**。`battle()` 的攻守角色是裁判傳進去的,
而規則從未定義過雙方同一小時互相移入對方格時誰是攻方。這是真缺口,現予補上。

#### 判定

雙方**都不換位**,各自停在原格。戰鬥發生,但沒有人奪下任何格子(勝方仍可依對照表逼退對方)。

**名義攻方＝該小時實際推進距離較長的一方。**
理由是物理的:走得越遠的部隊,越接近行軍縱隊姿態、砲兵拖得越後、通信越沒架好。

- 名義攻方吃 **從行軍中接戰 ×0.7**。
- 名義守方**不享 `被動防禦 ×0.85`**——它不是在防禦,它也在往前撞。
- 雙方的**工事一律為 0**:兩邊都移動過,`abandon_works` 已自動清空(人不在洞裡)。
- 地形照各自實際所在格計算。守方在森林就是 ×1.5,那不是獎勵,那是它真的站在林子裡。
- **伏擊 ×2.0 照常判定**:若名義守方確實未被對方偵獲,它仍然適用。撞上看不見的東西就是會更慘。

#### 若兩方推進距離完全相同

不指定攻守。改以**對稱雙解**:

1. 以 A 為攻方、B 為守方在 B 格解算一次;
2. 以 B 為攻方、A 為守方在 A 格解算一次;
3. **兩次結果的損失各以 50% 套用。**

雙方都吃 ×0.7、都不享 ×0.85,總傷亡量與單場戰鬥相當。
這樣就不需要一個任意的「誰是攻方」,也不會因為裁判怎麼挑而改變結果。

#### 為什麼要在發生之前定下來

因為一旦真的發生,任何判準都會直接決定誰勝誰負。
**本條在雙方尚未接觸時公告,裁判此刻不知道也不可能知道它將對誰有利。**
這與 `precedents.md` §十二(裁判在看到結果後才做出翻盤裁示)是同一個教訓。
