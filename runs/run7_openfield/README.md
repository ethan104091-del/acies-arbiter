# Run 7 「純戰場 The Open Field」

30×18 開闊地，雙方各三個步兵師、一個裝甲師、一個特戰旅，180° 鏡像對稱。
無地形目標、無城鎮、無航空兵。T0–T8 共 9 個 tick ＝ 54 小時，1944-08-25 06:00 起。

**勝負**：斬首即勝｜否則殲敵計分（人員 ×1、戰車 ×20、火砲 ×10）｜相當時比自損。
**自傷不計入對手戰功。**

## 與 Run 6 的差別

| | Run 6 | Run 7 |
|---|---|---|
| 工事 | 記在單位上 | **記在格子上**（man-hours），離開再回來還在、可被奪取、**會被砲擊打壞** |
| 彈藥 | 百分比、打不完 | **實數發數**，一個基數約一個 tick 連續射擊，每 tick 補 40% |
| 火力任務 | 只有一種 | **急襲／壓制／干擾**三類，各有獨占優勢 |
| 行軍中砲擊 | 可以 | **不可以**（裁示 18）。規避手段：抽離砲兵營留守射擊 |
| 砲擊殺戰車 | 65% 戰車死於砲擊 | **實質為零**，改以壓制癱瘓機動 |
| 友軍誤擊 | 無 | **有**，對含己方之格射擊時該編隊承受同波 50% |
| 落彈分析 | 只有方位與口徑 | 加測距：**夜間 ±1 格**、白天只給距離帶（裁示 34） |
| 偽裝 | 無 | 3 工時，完成後靜止時能見好一級，移動歸零 |
| 手冊 | 數字手抄 | **全部由程式自引擎常數產生** |
| 對手交付 | 一 tick 四到五個檔 | **一 tick 一個檔** |

```bash

python3 runs/run7_openfield/dispatch.py <tick>

# 2. 等雙方交回 命令_T<tick>.md

# 3. 寫 t<tick>.py 解算。骨架：

# 4. 存快照 snap_T<tick+1>start.json
```

## 四條不可違反的規則（`feedback_wargame_referee_leaks`）

1. **不得手寫任何單方內容。** 單方事實只能經 `arbiter.brief_md()` 送達。
   `dispatch.py` 的洩漏檢查是這條的機械化防線。
2. **對雙方的裁示須逐位元組相同**（放 `rulings/shared/`）。
   只對一方的解讀放 `rulings/to_<side>/`（裁示 7：對一方自身命令的解讀只回該方）。
3. **工具隔離。** 兩位指揮官各自只能讀寫自己的目錄，不得讀本 repo、對手目錄、裁判日誌。
4. **紀律逐條檢查。** 稽核必須在看到計分**之前**跑完（`precedents.md` §十二：
   Run 6 終局的修正方向與「當時誰落後」存在無法排除的相關性）。
