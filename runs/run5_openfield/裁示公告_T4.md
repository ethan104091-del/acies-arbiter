## 裁示 58 — 本局沒有「盲目彈幕」：砲擊必須有已偵獲的目標編隊

本引擎的砲擊解算以**目標編隊**為單位，沒有「對某一格面射擊」的機制。
因此：**未被該方任何單位偵獲的敵編隊，不能對其射擊**，也不能對疑似位置實施攔阻射擊。

裁示 56 的正面（砲兵不需自己看見，該方任一單位偵獲即可）與本條的反面
（完全沒偵獲就完全不能打）合起來，使**偵察單位成為砲兵的開火許可**。
打掉對方的觀測單位，等於讓其砲兵在師級視距（白天 3 格、夜間 2 格）之外失能。

**已知限制（一併公開）**：史實上 1944 年的砲兵確實會對疑似位置實施攔阻與擾亂射擊。
本引擎沒有這個機制。規則已於 T0 凍結，本局照現狀執行；此項記入 `precedents.md`
待下一局考慮（可能的補法：對格面射擊，效果按該格是否真有目標折算）。

## 裁示 59 — 哪些抽離的營可以進入森林

裁示 38 第 2 款當時只列舉了步兵營、特戰、偵察，未窮盡。完整判準是**該兵種的森林速率**：

| 抽離的營 | 森林速率 | 可否入林 |
|---|---|---|
| 步兵營 | 0.33 hex/hr | **可** |
| 工兵營 | 0.50 hex/hr | **可** |
| 偵察營 | 0.50 hex/hr | **可** |
| 特戰（旅或其抽離營） | 0.50 hex/hr | **可** |
| 裝步營 | 0.50 hex/hr | **可** |
| 牽引砲兵營 | 0 | **不可** |
| 戰車營 | 0 | **不可** |
| 防空營 | 0 | **不可** |

師級與旅級**整編隊**一律不得穿越森林（裁示 38 第 1 款不變），
因其建制內含戰車與牽引砲。要用森林就抽離上表可入林的營級單位。

## 裁示 60 — 構築工事的工時只有「移動或潰散」才歸零

同一格內由構築工事轉為完全休整、再轉回構築工事，**已累積的工時完整保留**。

工時歸零的條件只有兩個：**該編隊移動**（跨格或推進一小時），或**潰散**。
所以「挖到有頂蓋 → 休整清疲勞 → 再繼續加工」是可行的作息，不會白挖。

（反面：達到有頂蓋級（8hr）之後再繼續挖沒有任何額外效果，工事等級已到上限。）
