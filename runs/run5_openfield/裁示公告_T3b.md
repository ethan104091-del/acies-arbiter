## 裁示 54 — 對局長度：跑到 **Tick 8 結束**

手冊 §3 已載明「殲敵計分（撐到 **Tick 8 結束**）」。明確化其含義：

| | |
|---|---|
| tick 編號 | T0 ～ **T8**（共 9 個 tick） |
| global hour | gh0 ～ **gh53** |
| 起訖 | 1944-08-25 06:00 ～ **1944-08-27 12:00**（54 小時） |
| 終局結算 | T8 的第 6 小時（gh53）跑完後 |

戰報標頭的「Tick n/8」意思是「第 n 個 tick，最後一個是第 8 個」，**T8 存在且要打完**。

**剩餘的白天小時數（自 T3 起算）**：

| tick | 時段 | 白天小時 |
|---|---|---|
| T3 | 08-26 00:00–05:00 | 0（gh23 為黎明） |
| T4 | 06:00–11:00 | 6 |
| T5 | 12:00–17:00 | 6 |
| T6 | 18:00–23:00 | 1（依裁示 52，18:00 那小時算白天） |
| T7 | 08-27 00:00–05:00 | 0 |
| T8 | 06:00–11:00 | 6 |
| **合計** | | **19** |

## 裁示 55 — 兵種協同：師級編隊單獨作戰已計三種

兵種是依**編隊型別**對照，不是依其建制內的營種類逐一展開：

| 編隊型別 | 計入的兵種 |
|---|---|
| 步兵師 | 步兵、戰車、砲兵（**3 種**） |
| 裝甲師 | 戰車、裝步、砲兵（3 種） |
| 特戰旅 | 特戰、迫砲（2 種） |
| 偵察營 | 偵察（1 種） |
| 工兵營 | 工兵（1 種） |
| 抽離步兵營 | 步兵、戰車、砲兵（同其型別） |

協同倍率：1 種 ×1.0、2 種 ×1.3、3 種 ×1.5、**4 種以上 ×1.7**。

所以一個步兵師單獨作戰已得 ×1.5；**旁邊貼一個裝甲師會加上「裝步」而達到 4 種 → ×1.7**，
淨增益 +0.2。貼一個偵察營或工兵營同樣各加一種，效果相同。

## 裁示 56 — 砲擊只需**該方任一單位**偵獲目標

砲兵不需要目標落在自己的視距內。只要該方有任何單位偵獲該敵編隊，
射程內的砲兵即可對其射擊（`rules_v2` §7：戰場觀察員同 hour 回報）。

這是遠方偵察哨的主要價值之一：它讓後方砲兵能打到自己看不見的目標。

## 裁示 57 — 命令延遲於**發令時**依該編隊當時位置固定

不在生效時重算。一個編隊若在命令飛行途中離開前進指揮所半徑，其延遲不因此變長；
反之亦然。

**★ 併同揭露一個裁判的實作瑕疵（缺陷 17）**：我先前把每一份命令的延遲用「該方一個
代表性編隊的位置」算出來寫進佇列，但解算時卻**逐編隊**分別計算。這使戰報「延遲中的
命令」欄顯示的倒數，可能與實際生效時刻不符（差 1 小時）。

**已修**：自 T4 起，每一條命令依其**指名的編隊**在發令時的位置各自計算延遲，
戰報顯示的倒數即為實際生效時刻。本局 T0–T3 的解算一律採「逐編隊計算」的結果
（那才是規則的正確行為），受影響的只有戰報顯示，不影響已發生的事實。
