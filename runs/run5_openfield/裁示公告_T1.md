## 裁示 42 — 抽離營的裝備（★ 裁判錯誤，戰報已更正並重發）

**這是我的程式錯誤，不是規則問題。**

T1 戰報原本顯示某些抽離出的步兵營帶有「戰車 54、火砲 48」——那是整個師的裝備數字，
不是該營的。原因是我在補齊新生成單位的欄位時，套用了「該兵種的**師級**編制」，
於是一個 870 人的步兵營拿到了 54 輛戰車與 48 門榴砲：戰力錯、被擊毀時的計分錯

| 抽離的營 | 攜行裝備 |
|---|---|
| 步兵營、裝步營、偵察營、工兵營 | 無戰車、無野戰砲 |
| 防空營 | 無（40mm 高砲不是計分用的野戰砲） |
| 配屬戰車營（步兵師） | 戰車 54 |
| 戰車營（裝甲師 t1–t4） | 戰車 54 各 |
| 砲兵營（步兵師 a1–a3） | 105mm×12 各 |
| 砲兵營（步兵師 a4） | 155mm×12 |
| 自走砲營（裝甲師 sp1–sp3） | 自走榴砲×18 各 |

## 裁示 43 — 補給走廊的判定範圍

走廊是**該編隊所在橫排**（同一個 y）從它的 x 拉回本方邊緣的那一整條格子。

| 敵方位置 | 對該走廊的效果 |
|---|---|
| 站在走廊格上（同 y、且在編隊與補給源之間） | **切斷（0%）** |
| 距任一走廊格 1 格以內（含斜角） | **受威脅（50%）** |
| 更遠 | 完整（100%） |

所以：編隊在 (8,9)、敵戰鬥單位在 (5,8) → 敵距走廊格 (5,9) 僅 1 格 → **受威脅 50%**，不是切斷。
要切斷必須有敵單位**站上**同一橫排的走廊格。

**已知限制（一併公開）**：`compute_supply` 不為抽離的營級單位單獨計算走廊，
因此抽離單位的補給狀態在多數情況下沿用「完整」，除非其所在格恰好落在某個師的走廊上。
這對雙方對稱，且本局不修改（規則已於 T0 凍結）。

## 裁示 44 — 砲兵可以對森林格內的目標射擊

可以，沒有射線或入林限制。砲兵不需要進入森林才能打森林裡的目標。
森林對**目標**的效果反映在暴露係數上：`exposure_factor` 對森林格額外 ×0.7。

（`precedents.md §E8` 已記載此 ×0.7 的方向可能是反的——樹爆對無頂蓋部隊更慘——
但規則已於 T0 凍結，本局照現行值執行，重審留待下一局。）

## 裁示 45 — 同一格可否併設主指揮所與前進指揮所

**可以，但沒有意義。** 延遲階梯只看軍長所在：軍長駐前進指揮所且該編隊在作用半徑
（6 格）內 → 0 級；其餘情況一律 +1（有主指揮所）或 +2（無指揮所）。
在同一格併設兩個指揮所，軍長仍只在一個位置，效果等於只有前進指揮所生效，
半徑外的編隊照 +1。若欲同時取得「近處 0 級」與「遠處 +1 級」，兩者本來就同時成立，
不需要併設。

**斬首風險**：兩個指揮所在同一格，該格失守即同時失去兩者，且斬首判定只需一格。
分設兩格則風險分散但軍長只能在其中一格。
