## 裁示 45 訂正 — ★ 我上一份公告的最後一句是錯的

T1 公告的裁示 45 我寫了：「若欲同時取得『近處 0 級』與『遠處 +1 級』，兩者本來就同時成立，
**不需要併設**。」

**這句是錯的。** 實際程式行為是：

```
軍長駐前進指揮所且該編隊在 6 格內  → 0 級
否則，若「有主指揮所」            → +1 級
否則                              → +2 級
```

**沒有主指揮所時，前進指揮所半徑外的編隊會掉到 +2 級，不是 +1。**
所以要同時取得「近處 0 級、遠處 +1 級」，**必須兩個指揮所都保有**。已實測確認。

裁示 45 的其餘內容（同格併設合法、延遲階梯只看軍長所在、兩者同格則斬首風險集中）不變。
更正此條對雙方同時生效。

## 裁示 46 — 旅級編隊單獨計算補給走廊

會。`compute_saupply` 只跳過**抽離的營級單位**（`is_detachment`），

## 裁示 47 — 森林 ×0.7 與工事等級是**相乘**

相乘，不是取較低者。

```
砲擊暴露 = 該工事等級的暴露係數 × (在森林格 ? 0.7 : 1.0)
```

例：散兵壕（0.18）位於森林格 → 0.18 × 0.7 = **0.126**；
有頂蓋（0.10）位於森林格 → 0.07；無工事在森林 → 0.49。

（再次註記：`precedents.md §E8` 已質疑森林 ×0.7 的方向可能相反，
但規則已於 T0 凍結，本局照現行值執行。）

## 裁示 48 — 兵種協同計入相鄰 8 格內的友軍

計入。協同兵種數的判定範圍是「參戰編隊」**加上該戰鬥格相鄰 8 格內的所有友軍編隊」**，
不論該友軍是否被列為參戰單位。

因此一個位於相鄰格的裝甲師，確實會使該場戰鬥的兵種計數納入其戰車與自走砲。
四種以上兵種的協同倍率為 ×1.7（三種 ×1.5、兩種 ×1.3、一種 ×1.0）。

**對雙方同時成立**：緊密相鄰的密集配置提高協同倍率，但也讓同一波砲擊能同時威脅多個編隊
（密度係數與飽和上限是逐編隊獨立計算的，見手冊 §7）。

## 裁判主動揭露：一個規則漏洞，本局不修

「前進指揮所」在程式裡**沒有任何「必須比本方主力更前」或「必須接近敵方」的檢查**。
因此一方可以把前進指揮所設在自己的**後方縱深**（甚至與主指揮所同格、由重兵守備的森林內），
取得 0 級命令延遲，而**完全不承擔設計上原本要用來交換的斬首風險**。

本局已有一方這樣做，而且完全合法 —— 那是讀懂機制之後的正當發現。

**本局不修正。** 規則已依 `law_of_war.md` §0.1 於 T0 凍結，
為了鈍化一方的洞察而中途改規則，比失衡本身更糟。
本項記入 `precedents.md` 待下一局重審（可能的修法：前進指揮所須位於本方主力重心之前，
或距最近的已偵獲敵編隊若干格內）。

另一方若判斷這個做法有利，**本局同樣可以照做**，沒有任何規則阻止。
