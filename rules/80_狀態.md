# 80 狀態 — 組織度、潰散、投降、狀態機

> 推導、史實依據與沿革在 `rules/v1_archive/`（封存，不再是規範）。


## §0 狀態機

編隊狀態：`ACTIVE` → `ROUTED`（潰散）→ 恢復或 `DISBANDED`（解散）；`ACTIVE`／`ROUTED` → `SURRENDERED`（投降）。
潰散與投降的判定在每小時管線末尾、組織度自然恢復**之後**（用該小時淨值判）。具戰鬥資格者為 ACTIVE 與 ROUTED。

## §1 組織度衝擊

<!-- rulespec:org_impact -->
| 項目 | 值 |
|---|---:|
| 連續戰鬥 | 每小時 −2（連戰 6+ 小時起） |
| 被突襲 | −10 |
| 指揮所被毀 | −20 |
| 團長陣亡 | −5 |
| 友軍誤擊 | −10 |
| 工事減半 | ×0.5（散兵壕級起，門檻 0.35） |
| 自然恢復 | +1/hr（補給線完整） |

`impact = (傷亡% × 1.5 + 壓制 + 突襲 + 指揮 + 誤擊) × (工事 ? 0.5 : 1)`，自然恢復另加，**不被工事減半**。
戰車掩壕門檻 `FORT_TANK_TIER = 0.35`（淺掘對戰車無用）。
<!-- /rulespec:org_impact -->

組織度上限受疲勞（10_地形與移動 §4）與口糧危機（70_後勤 §5）扣減。遭干擾射擊的小時不得完全休整（30_火力 §2）。

## §2 潰散與投降

> 下表由 `rulespec.py` 產生（`--sync`）。散文可改，表格不要手改——手改會被測試抓到。

<!-- rulespec:status_thresholds -->
| 門檻 | 值 |
|---|---:|
| 潰散 org | < 25 |
| 潰散 24hr 傷亡 | > 30% |
| 潰散後撤 | 2 格 |
| 追擊倍率 | ×3 |
| 潰散恢復 | 6 小時後 org → 30 |
| 潰散解散 | 12 小時未恢復 |
| 投降 org | < 15 |
| 投降 食物 | RAT < 5% 且戰役 > 7 天 |
| 投降 無補給 | 連續 48 小時 |

潰散需**三條同時成立**：org 門檻 ＋ 24 小時傷亡 ＋（補給切斷 或 被包圍 或 信號中斷）。
★ 第三條使「補給完整時 org 歸零仍不潰散」——Run 5–7 三局零潰散、零投降（`docs/TODO.md` R8-C3、`law_of_war.md` §9）。
受降的看管兵力 ＝ 俘虜數 × 5%。
<!-- /rulespec:status_thresholds -->

- 潰散：狀態轉 ROUTED，向本方補給源強制後撤 2 格（不受移動速率限制），撤退途中可被追擊（×3）；6 小時後補給完整則 org 恢復至 30；12 小時未恢復即解散。
- 投降有兩條路：**自動**（條件成立，指揮官失去控制，不可能背信）與**自行示降**（指揮官下令，可被拒受）。兩者皆不可逆。受降方須派看管兵力（俘虜數 × 5%）並負擔口糧。
- 示降／受降的合法性與詐降見 `law/law_of_war.md` W2／W7。
