## §2 工事屬於格子（hex 記憶）

**工事屬於格子，不屬於單位。**

```python
state["works"]["11,9"] = {"man_hours": float, "by": side}
```

### 累計的是「工時 × 人數」，不是「小時」

```
挖掘：man_hours += 人數 × 時數 × DIG_RATE[兵種]
判級：該編隊工事級 = 50_工事 §1 的表查（該格 man_hours ÷ 該編隊人數）
```

**為何要除以人數**：若只記小時，一個 550 人的工兵營挖 8 小時，
一個 14,030 人的師進駐即白得一個有頂蓋——但那個營挖的是 550 人份的散兵坑，容不下一個師。

由此推出的三件事：

1. **一個師自己挖 8 小時仍是有頂蓋**（人數 × 8 ÷ 人數 = 8.0 hr/人）。與舊制行為一致。
2. **離開再回來，洞還在。** 行軍中該編隊防護為 0（人不在洞裡），停止即重新取用。
3. **工兵預挖給師用幾乎無效**——700 人挖 8 小時 = 8,400 man-hr，
   對一個 14,030 人的師僅 0.60 hr/人（淺掘）。
   這是物理，不是引擎偷懶：1944 年的工兵構築的是掩體、障礙、雷區等單點工程，
   師級散兵坑線一向是步兵自己挖的。

### 敵方佔領

**完整接收，不打折**（Run 6 勝方指揮官裁定）。攻下敵方陣地即得其完整工事，
使「奪取陣地」具有戰術價值。

### 摧毀

| 來源 | 摧毀量 |
|---|---|
| 間接火力（`bombard` / `bombard_hex`） | 殺傷單位 × `WORKS_DEMOLITION = 22.6` man-hr |
| 近戰（`battle`） | 該格 man_hours × 攻方戰力損失% × `MELEE_WORKS_MULT = 3.0` |

**下限為佔用編隊的淺掘級（0.5 hr/人）。** 被翻犁過的陣地不會變成平地，
會變成一片彈坑，而彈坑本身即掩體。此下限使「砲擊全滅工事」不可能發生。

校準（對一個 14,030 人的師）：

| 砲群 | 每小時削減 | 有頂蓋→散兵壕 | →淺掘下限 |
|---|---:|---:|---:|
| 單一步兵師砲兵（48 門） | 0.59 hr/人 | 8.4 小時 | 12.6 小時 |
| 兩個師的砲兵集中（96 門） | 1.19 hr/人 | 4.2 小時 | 6.3 小時 |

節奏依據：史實上的砲兵準備射擊以「小時到半天」為單位，非分鐘。

**衰減未實作。** 一局僅 54 小時，壕溝崩塌所需時間遠長於此。

## §3 偽裝作業

由玩家提出「用帆布和木棍偽裝」而作成。合法性早已明定於
`law/law_of_war.md`：夜襲、奇襲、**偽裝**、隱蔽、佯動均為合法戰爭詭計
（海牙第四公約第 24 條）。偽裝**裝備種類、陣地、番號、兵力規模**皆合法，不構成背信。

| 項目 | 內容 |
|---|---|
| 門檻 | 累計 **`CAMO_HOURS = 3.0`** 工時 |
| 工時速率 | 與構築工事同表（`DIG_RATE`） |
| 前提 | 該 hour **未移動**，且須**明確下令「偽裝作業」** |
| 效果 | 完成後，該編隊**靜止時的能見狀態好一級** |
| 失效 | **移動即歸零**（帆布帶不走）。**不給 hex 記憶**——隨隊裝備，與土工作業性質不同 |
| 開火 | 開火當小時仍為 EXPOSED（槍口焰、揚塵），但偽裝物留存，停火後恢復 |
| 工時池 | **與構築工事共用**——一小時只能擇一 |

「好一級」沿用引擎既有的轉換表（特戰旅的滲透隱蔽用的就是這張），**未新增任何係數**：

```
EXPOSED → STANDARD → CAMOUFLAGED → CONCEALED（封頂）
```

特戰旅的「好一級」與偽裝的「好一級」**可疊加**，但封頂於 CONCEALED。

### 無法實作的部分

「讓敵方把戰車誤判為火砲」**不實作**，理由有二且皆為硬限制：

1. 戰報由程式產生且報告真實編隊身分。要做誤判須新增「假身分」機制。
2. **裁判不得手寫任何單方內容**（00_核心 §2）。裁判若手打一份假情報進敵方資料夾，
   等於證明裁判可任意寫入單方內容——那條路必須永遠封死。

列為待決議題，見 `law/precedents.md`。

## §4 工時池

構築工事與偽裝作業共用同一小時的工時：一小時只能擇一。該小時移動過、不受指揮、或遭干擾射擊（30_火力 §2）者兩者皆不得實施。
**必須明確下令**；「固守」「戰備」「防禦姿態」都不是構工（裁示 33）。
