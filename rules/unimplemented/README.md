# rules/unimplemented/ — 有規格、引擎未實作

這些文件描述的是**真實存在的東西**（1944 年確實有城鎮戰、確實有天氣影響作戰），
規格也寫得完整。它們在這裡的唯一理由是：**引擎沒有實作，純戰場劇本也用不到。**

放在這裡而非 `archive/`，因為它們沒有被取代、沒有過時——只是還沒接上。

| 檔案 | 內容 | 為何未實作 |
|---|---|---|
| `urban_combat_v1.md` | 城戰逐棟、巷弄、暗道、平民、戰車進城 | 純戰場地圖只有開闊地與森林，無城鎮。《戰爭法》W4／W5／W6（對平民重砲、強制勞動、白磷）也因此無適用空間 |
| `weather_v1.md` | 天氣系統、能見度、地面狀況、空中支援可飛條件 | 純戰場劇本固定為「全程晴好」。天氣一旦實作，`recon_v1` 的視距與 `movement_v1` 的地面狀況都要接上 |

## 同樣未實作但仍留在 `rules/` 的部分

以下散在既有規格書中，尚未獨立抽出：

| 機制 | 住址 | 為何未實作 |

| 防空（AA）對 CAS | `combat_v1.md` §VIII、`determinism_v1.md` §VII | 同上，無 CAS 則無防空對象 |
