# 樞衡 Arbiter — 戰爭法與軍事法庭（v1，2026-07-30 制定）

本文與 `precedents.md` 平行：`precedents.md` 管**戰場如何解算**，本文管**戰後如何清算**。
兩者共用同一條紀律：裁示必須在還不知道誰受益之前作出。

**適用法源**：1907 海牙第四公約附件（陸戰法規慣例章程）、1929 日內瓦戰俘公約、
1925 日內瓦毒氣議定書。**只用 1944 年當時已生效的法**，不引用戰後才出現的規範
（1949 日內瓦四公約、1977 附加議定書、1980 CCW 第三議定書一律不適用）。

---

## §0 位階與時效（不可協商）

1. **不得事後立法。** 本禁令表在對局 T0 之前對雙方**對稱**公佈，其後只適用、不新增、不修改。
   戰後法庭只認定事實與量刑，**不得創設罪名**。紐倫堡與東京審判最大的法理瑕疵就是事後法，
   本系統不複製這個瑕疵。
2. **本表未列的行為即為合法。** §6 列出「已知但尚未開放」的罪名，正是為了防止它們日後被當成新罪追訴。
3. **審判條件（歷史結構，刻意保留）：**
   - **敗者**：有罪則受罰，罰則見 §5。
   - **勝者**：不受起訴，**無例外**（含 W7 詐降）。罪行仍列入戰史，
     記為「**未受審之罪行**」；若 §5.2 重播證明該罪行為勝因
     （扣除後勝方會敗），該次勝利降格為「**有瑕疵之勝利**」。仍然是勝，但與乾淨的勝分開記載。
   - 理由：只審敗者是史實；但若勝者完全不留紀錄，罪行對領先方的嚇阻力為零，法庭就只會在
     殘局開火，無法約束交戰過程。降格是最小干預下仍能約束領先方的手段。
4. 本文修訂只能在**兩局之間**進行，且修訂後版本自下一局 T0 起生效。
5. **引擎與法庭的分界（2026-07-30 補訂，違反過一次）。**
   **戰局之內只有事實。合法與否是戰後法庭的辯論，由裁判判決。**

   | | 誰做 | 內容 |
   |---|---|---|
   | 事實 | 引擎 | 誰在第幾小時對誰開火、誰做了什麼宣告、當時各方的客觀狀態與可觀察範圍 |
   | 認定 | 法庭 | 條號、寬限期是否已過、示降是否可信、該方是否明知、量刑 |

   本文所有標準（§1 各條要件、§3 明知、§4 寬限期、§5.2 量刑）都是**給法官用的**，
   **不得寫成程式裡的自動認定，更不得寫成自動制裁。**
   初稿曾把 W1／W2／W7 的認定寫進 `arbiter.py`，並讓「詐降者全軍喪失受降請求權」
   在局內自動生效 —— 那是未經審判就執行處罰，已全部移除。
   引擎現在只有 `record_engagement` / `record_fact`，無條號、無評價。

   附帶好處：每個 tick 的快照本來就存了全部客觀狀態，法庭可直接查證，
   不必信任裁判當時的判斷 —— 連我在局中是否偷偷做過認定，都可以被驗出來。

6. **罪責主體是編隊層級的指揮官**，判定單位為引擎中**最小的獨立追蹤編隊**
   （師、旅、以及被抽離的獨立營、偵察營、工兵營）。師長不為未在其視野內、
   未經其命令的下級行為負責。

## §1 甲類禁令：現行規則與 state 已足，即時生效

### W1 — 攻擊已喪失戰鬥力之編隊
> 依據：海牙第四公約第 23 條(c)「禁止殺傷已放下武器、或已失去自衛手段而投降之敵」

一編隊在同時滿足下列三項客觀要件後，即為「已喪失戰鬥力（hors de combat）」。
對方於**明知**（§3）並經過**寬限期**（§4）之後仍對其實施砲擊或地面突擊者，構成 W1。

| # | 要件 | 判準（現有欄位可直接查證） |
|---|---|---|
| A | **兵力潰滅** | `losses.personnel ÷ 建制人員 ≥ 70%`；**或** 累計傷亡 ≥ 50% 且 `org ≤ 25`；**或** `equip.guns` 與 `equip.tanks` 同時歸零且累計傷亡 ≥ 50% |
| B | **無還擊事實** | 前一小時未實施任何攻擊動作，且（火砲存量 0 **或彈藥歸零** **或** 補給狀態 = cut） |
| C | **無脫離能力** | 補給走廊狀態 = cut |

> **★ Run 7 修訂（2026-08-04，依 §0.4 於兩局之間為之）**：要件 B 增列「彈藥歸零」。
> 理由：Run 5、Run 6 合計 16 個 tick，本條**零次觸發**。病根不在法條而在彈藥——
> 舊制彈藥以百分比計，每 tick 補給 +22% 永遠大於最重消耗 15%，
> **任何編隊都不可能耗盡任何東西**（Run 6 打完 54 小時，雙方砲彈仍剩 91–96%）。
> 彈藥打不完 → 補給無所謂 → 沒人切走廊 → 要件 C 永不成立 → 本條永不成立。
> Run 7 起彈藥改為**實數發數**（一個基數約等於一個 tick 的連續射擊），
> 「打光彈藥且補給被切斷」成為可達狀態，而那正是要件 B 想描述的「已失去自衛手段」。
>
> **要件 C 未放寬。** Run 5 敗方曾主張放寬，被駁回，理由「一個能撤走的單位不是屍體」——
> 裁判接受該論證。正確的解法是讓切補給線變得有價值，不是降低門檻。
>
> **判準來源（[判例]）**：師級編隊在史實上約於 50% 損失時撤出戰線，70% 以上損失被視為
> 「被殲滅」而非「受損」。要件 B 的「未還擊」是把法律上的「已失去自衛手段」翻成本引擎
> 唯一能客觀驗證的事實。這三個數字是我訂的，可以被推翻——但只能在兩局之間，不能在判決時。

> **要件 A 必須用累計傷亡（`losses.personnel`），不得用當前人員數或 `strength`。**
> 兩個理由，皆為 Run 4 校準（§8）實測所得：
> ①當前人員數會被**抽離**污染 —— BLU-2 人員從 14,030 掉到 10,852，其中 2,610 是抽離三個營，
>   實際戰損只有 268；②`strength` 欄位與傷亡幾乎脫鉤 —— RED-1 損失 3,024 人（21.6%）
>   與 29 門砲（六成），`strength` 只從 100 掉到 95。

**§1.W1 的合法替代手段**：**停火並維持包圍／接觸**。該編隊在要件成立後已無法作戰、無法補給、
無法脫離，圍而不打**不損失任何作戰利益**。因此 W1 禁止的不是「取勝」，而是**在屍體上收割殺傷分數**。
這一點與計分函數（人員 ×1）直接衝突，是刻意的：它讓「繼續打」在打的當下就是法律風險。

### W2 — 不受降、屠殺已投降之編隊
> 依據：海牙第四公約第 23 條(c)；1929 日內瓦戰俘公約

`combat_v1.md`〈投降（Surrender）觸發條件〉已定義：**Org < 15，且任一條成立** ——
被四面包圍（無退路）／食物 < 5% 且戰役 > 7 天／整師指揮官陣亡 + 信號中斷／連續 48 hour 無補給。
後果為 `SURRENDERED`、人員變 POW、裝備被繳獲。

**四條件在本劇本的實際可達性（2026-07-30 誠實盤點）：**

> **★ 2026-08-08 更正：本節原以「48 小時劇本」推算，劇本實為 54 小時**
> （T0–T8 共 9 個 tick；`scenario_open_field.md` §0 已更正）。下表已依 54 小時重算。

| 條件 | 狀態 |
|---|---|
| 被四面包圍（無退路） | **可達**，`encircled()` 由相鄰格幾何判定 |
| 連續 48 hour 無補給 | **可達**（原註「極限」係按 48 小時劇本推算）：54 小時劇本中，自 gh0–gh5 起斷補即可於 gh48 起成立，**恰好落在最後一個 tick**。仍需從開局即全程斷補，實務上極難 |
| 食物 < 5% 且戰役 > 7 天 | **不可達**：本劇本 54 小時，遠短於 7 天 |
| 整師指揮官陣亡 + 信號中斷 | **空條件**：信號中斷已實作（`signal_lost`），但**師長陣亡沒有任何模型** ——本引擎無幹部傷亡，而斬首在本劇本是即時勝利、遊戲會直接結束 |

空條件與 W3 同樣處理：明文標示，**不得以代理指標偷偷補上**。
（初稿在 `surrender_conditions` 裡引用了一個沒有任何地方會設定的 `cp_signal_lost`，
等於讓這條看起來有效其實永遠不成立，已改為明文空條件。）

**通訊（`signal_lost`）**：被四面包圍**且**補給切斷 → 與司令部失聯。
效果是**新命令送不進去**，不是失去戰鬥力 —— 該編隊繼續執行最後一道既有命令。
這正是「自行投降」這條路存在的機械理由：失聯的部隊要投降，只能由現地自己決定。

#### §1.W2.0 投降的兩條路（2026-07-30 依指揮官意見改定）

`combat_v1.md` 寫的是「觸發」，字面讀法就是**部隊自行投降**。這個讀法是對的，
而且它自帶一個關鍵後果：**指揮官同時失去對該編隊的控制權。**

| 路徑 | 觸發 | 指揮官的控制權 | 可否用於詐降 |
|---|---|---|---|
| **自行投降** | org < 15 且四條之一，自動 | **失去** ——不接受命令、不移動、不開火 | **不可能**（沒有人能命令它開火） |
| **手動示降** | 指揮官下令，**無任何門檻、隨時可下** | 保留 ——仍可被命令行動 | **可以**（這就是 W7） |

兩條路的共同點：**不可逆**，且**對手都可以選擇不受降**。受降從來不是義務。

> **初稿的錯與其修正。** 初稿把投降拆成「資格（可逆旗標）／示降（宣告）」兩段，
> 理由是怕自動投降造成「非自願的戰爭罪」：自動投降 → org 回升 → 繼續作戰 → 詐降，
> 但沒有指揮官做過這個決定。
> 這個顧慮在「自動投降同時剝奪指揮權」之下**根本不存在** —— 它不會再作戰，
> 因為沒有人能命令它。初稿因此白加了一道門檻，還順手把手動示降也擋掉了。

這個分法同時把詐降的位置放正了：**只有手動示降能詐降。**
自行投降是部隊自己不打了，指揮官插不上手，無可歸責之人；
手動示降是指揮官還握著這支部隊卻做了宣告 —— 那才是海牙第 23 條(f)
所針對的「不當使用休戰旗」，一個刻意的行為。歸責的分界剛好落在控制權上。

**共同的效果（兩條路皆同）**：
- 已投降者**不得主張防禦戰力**（`unit_cp` 守方回傳 0）。放下武器就不能再算抵抗。
- 但手動示降者若被指揮官命令**主動攻擊**，攻方戰力照算 —— 那正是詐降的內容，
  引擎不禁止，只把「該編隊曾於 gh N 宣告示降、卻於 gh M 開火」記成事實。
- 不投降而戰至全滅完全合法，不構成任何罪名，也不構成瀆職。

#### §1.W2.1 可信度：對手當場決定信不信，法庭事後決定他信不信得有理

四條件不是「能不能示降」的門檻，也不是引擎會去計算的東西，
而是**法庭日後判斷「對手不信是否合理」時所適用的證據標準**：

| 示降當時的客觀狀態 | 敵方繼續攻擊 |
|---|---|
| 符合四條件（Org < 15 且被圍／斷補／斷糧／指揮斷絕） | **構成 W2** ——不信不合理 |
| 不符合（例如 95% 兵力的滿編師舉白旗） | **合法** ——合理不信任（reasonable disbelief） |

- 這符合當時的法：投降須明確且無條件，情況曖昧時攻方有裁量餘地。
- **可信度按各時點分別認定。** 示降當時不可信、其後被打到真的崩了 →
  法庭得認定可信度自該時點起成立，停火義務亦自該時點起發生。
  引擎不做這件事：它只在每次交火時記下對象當時的 org、補給、包圍、傷亡率，
  由起訴方自行舉證是哪一小時開始成立。
- **戰報不告訴任何一方某個示降「可不可信」。** 只給該方本來就觀察得到的事實
  （§3.1 的戰鬥力狀態旗標、概估戰力、工事狀態）。一個標著「已宣告示降」
  而戰鬥力狀態仍是「有效」的編隊，可疑之處由指揮官自己看出來。
  這是裁判不該代替指揮官思考的地方。

#### 罪名

- **W2a 不受降**：對已投降（兩條路皆同）的編隊，於明知並經寬限期後繼續攻擊。
  自行投降者的可信度通常無爭議（其客觀條件依定義已成立）；手動示降者的可信度依 §1.W2.1 認定。
- **W2b 屠殺俘虜**：已繳獲之 POW 於後續 tick 自人員帳中消失而無合法解釋（移交、後送、逃亡）。

**合法替代**：受降。受降方仍取得該編隊全部人員之計分（§5.2），因此 W2 不存在「不得不犯」的情境。

### W7 — 詐降（背信）
> 依據：海牙第四公約第 23 條(f)（禁止不當使用休戰旗、敵方國旗與軍階標誌、日內瓦公約標誌）

已宣告 `SURRENDERED` 的編隊，於敵方停火或前進受降後，實施任何攻擊動作者，構成 W7。
**構成與否由法庭認定**；引擎只登錄宣告時刻與開火時刻兩個事實。

- **W7 只能經手動示降發生。** 自行投降者已脫離指揮，不可能被命令開火（§1.W2.0），因此凡有 W7 的事實，必然出於指揮官的決定，可歸責。

#### W7 是刻意留著的路，不是被封住的路

詐降是本表唯一**同時取得作戰利益與法律盾牌**的罪行：突破換來的分數是我的，
敵方一開火反而是他犯 W2。這個組合看起來必須封殺，但**封殺是錯的** ——
詐降是唯一讓「受降」變成真決定的東西。若它不可能，受降就零風險，
W2 也就成了一條沒有成本的規則。

> **修訂紀錄（2026-07-30）**：本條初稿設了兩道禁止性防線 ——
> 「示降須先取得資格」與「W7 不受勝者豁免」。兩者都已刪除。
> 前者是把 `combat_v1` 的「投降觸發條件」誤改寫成「准許宣告的門檻」，
> 既不寫實也違背本系統讓指揮官自由行動、由裁判逐案裁示的初衷；
> 後者是為了怕失衡而推翻 §0.3 已定的「只審敗者」結構。
> 現在的處理是：**不禁止，只定價，並把判斷交還給對手。**

因此 W7 的約束全部來自「對手可以怎麼反制」與「事後要付什麼代價」，沒有一道是禁止：

**① 可信度：對手可以合理不信任。**
示降不可信時（見 §1.W2.1），敵方繼續攻擊完全合法。滿編師舉白旗換不到停火。
但要注意這道並不像初稿以為的那麼硬 —— 手動示降沒有門檻，所以一支**尚有戰力**的編隊
確實可以宣告示降並保留攻擊能力；它換不到的只是「對手不受降就違法」這個法律效果。
詐降真正的價值本來也不在該編隊自身的戰力，而在誘使敵方圍攻兵力離位，因此需要 ②。

**② 受降程序不得要求受降方暴露。移動義務在示降方。**
受降方有權要求示降編隊**主動離開其陣地、繳出重裝備、向受降方指定位置徒步集中**。
受降方**無義務**前進接收、無義務離開工事、無義務停止對**其他**編隊的火力 ——
停火義務只及於該一個宣告示降的編隊。對拒絕執行受降程序的編隊恢復攻擊，**不構成 W2**。

**③ 停火主張自攻擊時點起不再受保護（**法庭之認定**，非引擎之自動效果）。**
示降編隊一旦實施任何攻擊動作，法庭將認定其停火主張自該時點起失效、且不適用寬限期，
受降方於其後還擊不構成 W2。引擎只記下「該編隊曾於 gh N 宣告示降、並於 gh M 開火」
這兩個事實（`firing_units_that_had_declared_surrender`），不作認定、不撤銷任何權利。

**④ 局內真正的代價來自對手的選擇，不來自規則。**
受降從來不是義務，而是一個決定。對手看過一次詐降之後，會不會再受降，
是他自己的判斷 —— 規則不強制，引擎不執行。而其後果落在詐降方全軍：
所有陷入絕境的編隊從此可能只能戰至全滅。

這是聲譽機制，也是現實世界裡這條法真正的執行方式 —— 遵守它的理由通常不是怕受審，
而是怕沒人再接受你的投降。它比任何自動制裁都強，因為它由對手執行，不需要法庭。

因此 **§0.3 的勝者豁免對 W7 完全適用，沒有例外**：勝者詐降不受起訴，

## §2 明文合法（防止罪名蔓延）

以下行為在 1944 年的法與本系統中**明確合法**，不得以任何名義追訴：

- **攻擊敵指揮所、斬首作戰** —— 指揮所是合法軍事目標。
- **切斷補給走廊、圍困使其耗盡** —— 圍城與斷補在 1944 年合法（以饑餓為作戰方法針對平民的
  禁令是 1977 年附加議定書以後的事）。
- **追擊潰散（`ROUTED`）部隊，含 `combat_v1.md` 的 ×3 追擊傷亡倍率。**
  潰散不等於投降：潰散部隊仍在移動、仍可能重整（6 hour 恢復 Org 30），未失去自衛手段。
  這是 W1 最重要的邊界 —— **追殺逃兵合法，砲擊已癱瘡的殘部才是罪。**
- **砲擊仍有戰鬥力的編隊，無論其是否構築工事、無論傷亡多寡。**
  工事 0 而挨 198 門砲致每小時死 200 人，若該編隊仍在還擊或行動，即為合法作戰而非屠殺。
- **對戰鬥員使用白磷**（見 W6 之合法段）。
- **夜襲、奇襲、偽裝、隱蔽、佯動** —— 合法戰爭詭計（ruse of war）。
- **在對方尚有還擊能力時的全滅性攻擊** —— 合法。

## §3 明知（故意／過失的分界，適用全部禁令）

- 戰報（程式產生，見 §3.1）向該方顯示過構成要件之狀態 → **明知，可起訴**。
- 未顯示（不在其視野內、未達持續接觸、平民疏散狀態未經其偵察確認） → **過失，不起訴**。

「我不知道」在本系統是可查證的抗辯：戰霧本來就逐方記錄每一方在每一時點看得見什麼。

### §3.1 通知機制（唯一必要的程式改動）

`brief_md` 對該方**當前可觀察**且處於**持續接觸**（本方正在對其射擊，或連續 ≥2 小時在視野內）
的敵方編隊，加一欄三級定性旗標：

```
戰鬥力狀態： 有效 ／ 殘破 ／ 未見還擊（自 gh## 起） ／ 潰散中 ／ 已解散
　　　　　　（前綴）已宣告示降（gh##）
```

★ 這一欄全部是**觀察結果，不是法律結論**。「未見還擊」不等於「已喪失戰鬥力」——
後者是 W1 要件 B 加上要件 A、C 的合併結論，由法庭認定。旗標也**不會**告訴任何一方
某個示降可不可信、或開火會不會違法：那是指揮官自己要判斷的，也是他事後要辯的。

- 只給定性旗標，**不給對方的 org、傷亡與兵力原始數字**（那仍是戰霧保護的資訊）。
- 城戰劇本另加：該分區之**平民疏散狀態**（已疏散／部分／留城），僅在該方偵察確認後顯示。
- 依反洩漏規則第一條：此欄位一律由程式從 state 產生，我不手寫任何單方內容。

## §4 寬限期 = 該方自身的命令延遲

要件全部成立並經戰報通知後，寬限期為**該方當時的命令延遲時數**

## §5 程序與量刑

### §5.1 程序

| 角色 | 誰 | 權限 |
|---|---|---|
| **檢察** | 雙方指揮官各自 | 只能以**自己合法取得的情報**提出起訴書。不得引用戰後才知道的事實。 |
| **事實與量刑** | 引擎 | 重播計算（§5.2）。數字由程式產出，不由我開口。 |
| **有罪／無罪** | 裁判（我） | 只判要件是否成立。**不決定損害金額。** |

- 起訴時點：終局結算之後、戰史定稿之前。
- 舉證責任在檢察方；任一要件無法從其合法情報證明者，起訴駁回。
- **濫訴反噬**：被駁回的起訴記入該指揮官的跨局登記簿，降低其後續對局的申辯權重。
- 我不主動起訴。理由與 `precedents.md` §0 同：讓裁判兼任唯一控方，我的中立性無法被驗證。

### §5.2 量刑：用重播算，不用形容詞

零擲骰＋每 tick 快照 ⇒ 法庭可以計算反事實。

```
把違法動作自命令中刪除（改為該罪名對應的合法替代手段）
→ 自要件成立當時的快照重播至終局
→ 不法收益 = 實際分數 − 反事實分數

罰分 = 不法收益 × 2
```

- **×2 的理由**：一倍吐回不法收益（disgorgement），一倍為罰。使「犯行被定罪」必為淨負，
  而「犯行未被定罪」（＝該方贏了）仍為淨正。期望值 = p(勝)·收益 − p(敗)·2·收益，
  因此只有在**判斷自己會贏**時犯行才划算——這正是史實上的誘因結構，刻意保留。
- **平民傷亡不計入戰場分數，只計入罰分**：平民 ×1（與人員同權）。理由：計分函數是軍事成果的
  度量，殺平民不是軍事成果；但它是可量化的損害，所以只出現在判決書。
- **POW 計分與受降成本**：受降取得之 POW 以人員 ×1 計入受降方，與殲滅同權 ——
  受降在分數上不吃虧，W2 因此沒有「不得不犯」的藉口。

  但**淨值不同**，因為受降有現成機制可承載的實際成本：
  | 成本 | 現成機制 |
  |---|---|
  | 俘虜要吃飯 | POW 人數自受降方的 `resources.RAT` 池支出 |
  | 俘虜要看管與後送 | 受降方須抽離兵力看管（抽離營機制已存在，Run 4 藍軍抽過三個營） |

  這一條同時解決一個否則會讓 W2／W7 變成空條文的問題：**在單純的殲敵計分下，投降永遠不理性。**
  投降＝全員計入敵方；戰至全滅＝只損失一部分，而且還把敵人綁在原地。理性選擇永遠是玉碎。
  加入受降成本後，示降方的收益變成**把後勤負擔丟給敵人** —— 這正是史實上大規模投降真正的
  作戰效果。三件事因此同時成立：投降有理由、受降有代價、不受降沒有藉口。
- 判決書須載明兩個分數與差額，任何人都能用倉庫裡的快照重跑驗證。
- 勝方之罪行同樣跑此重播，但結果只用於 §0.3 的降格判定，不轉為罰分。

彈藥可耗盡 → 切走廊有價值 → 要件 C 可成立。中間那一步是**指揮官的選擇**，不是規則。

### 裁定

**不修 W1 要件 C，也不修 `combat_v1` 的潰散條件。** 三個理由：

1. Run 5 敗方主張放寬 C 時被駁回，理由「**一個能撤走的單位不是屍體**」。
   該論證與當時一樣成立。門檻當初訂得嚴，正是為了不把一般消耗戰入罪
   （§8 的 Run 4 校準已驗證這個設計意圖達成了）。
2. 曾考慮「org ≤ 5 持續 ≥ 3 小時視為指揮鏈中斷」以打通潰散路徑，**未採用**。
   它會在同一局內同時改動法條與狀態機，使 Run 8 的結果難以歸因；
   且潰散並不會使 W1 成立（`ROUTED` 的編隊仍在移動，正是 §2 明文合法的追擊對象）。
3. **修法只能在兩局之間，而現在正是兩局之間** —— 所以「暫時不修」是一個裁定，
   不是拖延。它可以在 Run 9 之前重新檢討，屆時多一局的證據。

### 因此明文記載

> **W1 在本劇本的尺度下可能是事實上的空條文。**
> 它不是因為法條寫壞了，而是因為在 54 小時、雙方鏡像 TOE、
> 補給源即本方邊緣的純戰場上，**深入敵後佔住走廊格並守住它，代價可能永遠高於收益。**

這與 §1.W2 的「空條件」、§1.W3 的「空條文」同樣處理：**明文標示，不得以代理指標偷偷補上。**
裁判不得為了讓戰爭法「有戲」而放寬要件、也不得以任何近似指標代替要件 C。

### 唯一允許的作為：把已存在的誘因說清楚，而不是改規則

彈藥實數化之後，「切斷走廊 → 補給為零 → 砲兵一個 tick 內打光」在**現行規則下已經成立**，
只是從未有人嘗試。手冊的開局提示應明白寫出這條因果——
**那是揭露資訊，不是修改規則，且對雙方對稱。**

若 Run 8 在完整揭露之後仍無人切走廊，則上述「代價高於收益」的判斷即得到第二次驗證，
屆時要修的是**劇本的幾何**（補給源、地圖縱深、時長），而不是法條。
